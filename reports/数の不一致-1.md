## ① 三つが何を数えていたか

| | 数えていた物 | 写せますの札**自身**を | 目次に |
|---|---|---|---|
| **釦の残N** | `mergedTodo()` ＝ 写した印の無い札＋写した印の無い通知 | **入れていた**（ふるいが無かった） | 出していた |
| **目次の行数** | 同じ `mergedTodo()` | 同上 | 同上 |
| **写せますの札の N** | 「前に知らせてから増えた札の数」**＋自分の一枚** | **足していた**（2026-08-30 の決め） | — |

**三つとも「写せますの札」を一枚として抱えており、しかも抱え方が違っていた。**
`+1` は必ず一枚を足すが、パネルの側は**その札が写した印を持てば消える**。
ここで数が割れる——2026-09-04 の実測が「釦 残2／3件・目次2行・知らせ 写せます（3件）」。

## ② 揃え方 — 写せますの札は、数にも目次にも入れない

**あれは「数の知らせ」であって仕事ではない。** 貼っても中身は無く、
数えると「何件写せるか」を自分自身で水増しする。

- **見張り**（`watch-notify.ps1`）… `$nShow = $n + 1` → **`$nShow = $n`**
- **返事パネル**（`panel.html` v116）… `isCountCard()` を足し、`mergedTodo()` の入口で外す。
  **数・目次・写す中身のすべてから外れる**（写しに入る物はこのふるいを通った物だけ）

```js
function isCountCard(d) {
  return /^写せます（[0-9]+件）$/.test(String((d && d.message) || '').trim());
}
```

三つとも **写した印の無い、中身のある札の数**を指すようになった。
