## ③ 鍵の作り直し方を置いた

**置き場は `~/.claude/KEY-REBUILD.md`**（非公開の蔵へ毎日写る側）。
**鍵の中身は一字も書いていない**（`gh…`・`github_pat_`・`sk-ant-`・UUID・題の字面を機械で数えて **0件**）。

**中身の柱**

1. **`gh` の認証** … `gh auth status` で見る → `gh auth login`（GitHub.com／HTTPS／ブラウザ）→
   要る権限は `repo`・`read:org`・`gist` → `gh api user` で確かめ → **古い札を Authorized OAuth Apps から取り消す**。
   ＊札は keyring に入る。**`remote` の URL に埋め込まない。**
   ＊使用量が使うのは**別の札**（Claude Code の `.credentials.json`）。切れたら **`/login` で入り直す**。
2. **healthchecks の check** … Add Check → 間合いと猶予（①見張り 5分/5分・②窓 10分/10分）→
   **①は `hc-watch.txt` へ一行**、**②は `inbox-watch.ps1` の `$HC_URL` を書き替えて常駐を起こし直す**
   （常駐は立ち上げたときの中身のまま走るため）→ 記録が `code=0 OK` になるのを見る → **古い check を消す**。
3. **ntfy の題** … **題は合言葉そのもの**。`kh-` ＋十六進48字以上。短い字・意味のある字にしない →
   `rc-ntfy-topic.txt` へ一行 → iPhone で新しい題を購読 → 試しを一発 → **古い題の購読を外す** →
   古い綴りは `.retired-<日付>` で残す。
   ＊**題の綴りは蔵に入らない。写しはどこにも無いので、無くしたら作り直す**（数分で済む）。
4. 作り直したあとに見る三つ … `pipe-warn.log` の末尾が `ok`／`hc-watch.log` が `code=0 OK`／
   返事パネルの状態の一行が動いている。
