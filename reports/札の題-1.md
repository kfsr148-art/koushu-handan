## 2. 札の題はどこから取っていたか

**`~/.claude/work-note.txt` の `件名:` の行だけ。**

| 何 | 場所 | 行 |
|---|---|---|
| 読む所 | `~/.claude/inbox-watch.ps1` | **L306** `if (… -match "^件名[:：]\s*(.+)$") { $subj = $matches[1].Trim() }` |
| 空のときの置き字 | 同上 | **L314** `if (-not $subj) { $subj = "（件名なし）" }` |
| `state.json` へ入れる所 | 同上 | **L462** `'"subj":' + (ToJson $subj) + ','` |
| パネルが読む所 | `panel.html` | **L1936** `var subj = String(d.subj || '');` ／ **L1938** `lastSubj = subj;` |

**前の state を引きずる作りだった。** 正確には「控え（`work-note.txt`）を働き手が書き直すまで、
前の回の件名が出たまま」。作法25 は「件名は作業の切り替え時点で書き換える」と定めているが、
**書き直すのは働き手なので、書き直す前の数分は必ず古い名が出る。**
今回は 05:21 に枠を受け、控えを書き直す前にご覧になったため、05:22 開始の札に
「通知の題-5」が出ていた。

## 3. 直し ── 控えより新しい枠が来ていたら、その印を題にする

`~/.claude/inbox-watch.ps1` **L310-341**。

```powershell
# ・last-order.txt の一行目の刻（枠を受けた刻）
# ・work-note.txt の更新時刻（控えを書き直した刻）
#   枠のほうが新しければ、印を題にする。
$ordMark = ''
…
if ($oAt -gt $noteAt) {
  $line1 = (($ol1[1]) -replace '^﻿', '').Trim()
  if ($line1 -match '^印[:：]\s*(\S+)') { $ordMark = $matches[1] }
  elseif ($line1) { $ordMark = $line1.Substring(0, [Math]::Min(24, $line1.Length)) }
}
…
if ($ordMark -and $alive -gt 0) { $subj = $ordMark }
```

**決めごと。**

- 見分けは**刻の比べ**だけ。枠が控えより新しければ印を出す
- **控えが枠より新しくなれば、控えが勝つ。** 働き手が件名を書いた時点でふだんの表示へ戻る。
  **自然に直る形**にしてあり、直しっぱなしにならない
- 印が読めない枠（`印:` の行が無い）は、**枠の頭24字**を出す
- **窓が落ちている回（`$alive -eq 0`）の置き字は上書きしない。**
  あれは件名ではなく状態そのものを語る字（「Claude Code は動いていません」）
