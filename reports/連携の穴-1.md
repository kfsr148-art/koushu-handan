## 6. 時計の突き合わせ

**揃えていない。三つとも別々の時計を見ている。**

| 何の刻 | 出どころ | 合わせているか |
|---|---|---|
| **VAIO の機械の刻** | Windows の時計 | **合わせていない。`W32Time` サービスが停止している**（`Stopped` / 起動 `Manual`）。同期先は `time.windows.com` と設定されているが、**サービスが動いていないので同期は走らない** |
| **GitHub の commit の刻** | `git` が**VAIO の時計**を打つ | VAIO の時計そのもの。**GitHub 側の時計ではない** |
| **パネルに出る刻** | **二種類が混ざっている** | 下記 |

**パネルの刻が二種類混ざっている。**

- **VAIO が書いた値** … `state.json` の `orderAt`（字）・`statAt`／`startedAt`／`at`（epoch秒）。
  「指示を受けた」「開始」がこれ
- **見ている端末（iPhone）の時計** … `Date.now()`。**`panel.html` L784・L931・L1239・L1245**。
  **「経過N分」「終了予定」「HH:MM 更新」がこれ**

**つまり「経過」と「終了予定」は、iPhone の時計から VAIO が書いた epoch を引いている。**
二つの時計がずれれば、**そのままずれが出る**。突き合わせも補正もしていない。

**いまのずれ（実測）** … VAIO の `git commit` の刻と GitHub が受けた刻の差は、
④の表の全12件で **3〜8秒**（commit 3:37:28 → 組立開始 3:37:33）。
**いまは合っている。ただし合わせ続ける仕掛けが無いので、放っておけばずれる。**
台帳の刻-1 で見た「私が手で打った刻が最大6時間ずれていた」のとは別の話で、
**あちらは人、こちらは機械**。機械の側は**いま**は合っている。
