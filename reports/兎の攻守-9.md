### 5-2. ③を `fillWeak === 0` に差し替えたときの並び

| 並び | 行 | 条件 | 返す | ③差し替え後に届く範囲 |
|---|---|---|---|---|
| ① | L4021 | スイッチが切ってある | `''` | 変わらない |
| ② | L4022 | **`typeof a.totalBlocks !== 'number'`** | `''` | **見る値が合わなくなる**（下記） |
| ③ | L4023 | **`a.fillWeak === 0`** | `'a'` | `fillWeak` が 0 の行 |
| ④ | L4024 | `a.fillWeak >= 2` | `'d'` | **`fillWeak` が 1 以上**しか来ない → 実質 2以上だけ |
| ⑤ | L4025 | `a.fillGood >= 3 && a.goodShapes <= 3` | `'d'` | **`fillWeak` がちょうど 1 の行だけ** |
| ⑥ | L4026 | — | `''` | 残り |

**③と④は排他で、競合しない。** `fillWeak === 0` で返った行は④に届かず、④に届く行は必ず `fillWeak >= 1`。

**⑤は届くが、4000行では一度も成立しない。**

| | 件数 |
|---|---|
| `fillWeak == 1`（⑤に届く行） | **1645** |
| そのうち ⑤ が成立（`fillGood>=3` かつ `goodShapes<=3`） | **0** |
| （参考）⑤ が成立する行（`fillWeak` を問わず） | **59** |
| （参考）そのうち `fillWeak == 0` | **59**（全部） |
| （参考）そのうち `fillWeak >= 2` | **0** |

⑤が成立する59件は**すべて `fillWeak == 0`** なので、③で先に `'a'` が返り、**⑤へは届かない**。
したがって **⑤を残しても外しても、4000行では票が一件も変わらない**（0件）。

＊ただしこれは**この母集団での実測**であって、論理的にありえないわけではない。
　`fillGood + fillWeak <= fillRemain <= 4` なので、`fillWeak=1` かつ `fillGood=3` は
　`fillRemain=4`（確定面子0）なら成り立ちうる。4000行では0件。

**②の見る値** … ③が `totalBlocks` を読まなくなるので、`typeof a.totalBlocks !== 'number'` は

⑤`undefined >= 3` → false と流れて **⑥で `''`（黙る）** に落ちるので、
**②を直さなくても危ない返り値は出ない**。
