## 3. 消していた経路と、その直し

### 経路

`~/.claude/notify-record.ps1` **L88-110** に「**同じ題（本文の一行目＝件名）の行が既にあれば、
中身が増えるときだけ置き換える**」という決まりがある（2026-08-23 の決め）。
同じ件の知らせが何本も並ばないようにするためのもの。

**ところが、溜めをまとめて出した札は、本文の一行目が必ずこうなる。**

```
この間にまとまった知らせ 2本
```

**中身が何であれ、一行目が同じ。** だから機械は「同じ件」と読む。

| 刻 | まとめ札の中身 | 一行目 | どうなったか |
|---|---|---|---|
| 03:55 | （二本） | `この間にまとまった知らせ 2本` | 残った（厚かった） |
| **04:28** | **穴の直し-1① の報告** ＋ 写せます | `この間にまとまった知らせ 2本` | **05:06 に消された** |
| 05:06 | 通知の題-5 の報告 ＋ 写せます | `この間にまとまった知らせ 2本` | 残った |

05:06 の札は 04:28 の札より**厚かった**ので、置き換えの条件
（項目数も字数も減らない）を満たし、**04:28 の行が丸ごと消えた。**

**返事パネルに一度も現れないまま消えたので、押しても写せるはずがなかった。**
釦の数と写しの拾いは、どちらも「そこに無い札」を数えていない点で正しく一致していた。

### 直し

`~/.claude/notify-record.ps1` **L95-106**。
**一行目が「まとめの見出し」の形をしているときは、置き換えを掛けずに足す。**

```powershell
$subj1 = (($body -split "`r?`n")[0]).Trim()
# まとめ札は毎回中身が違うので、そもそも同じ件ではない。
if ($subj1 -match '^この間にまとまった知らせ\s*\d+\s*本$') { $subj1 = '' }
if ($subj1) { …これまでどおりの置き換え… }
```

二通りで確かめた。

| 一行目 | どうなるか |
|---|---|
| `この間にまとまった知らせ 2本` | **置き換えを掛けない（そのまま足す）** |
| `通知の題-5（😽 の押し送りが…）` | 置き換えを掛ける（同じ件名なら差し替え・今までどおり） |

**ふつうの札の重複よけは、今までどおり効く。** 止めたのはまとめ札の分だけ。

　`notify-record.ps1` は見張りが呼ぶたびに立ち上がるので、起こし直しは不要。
