### 何が起きていたか

| 刻 | 何が溜まったか | 名乗り |
|---|---|---|
| **04:25:03** | 仕事が終わった知らせ | **`done`** ← 押し送りが出る |
| **04:26:04** | **写せます（20件）** | **`ready`** ← 押し送りは出ない |

二本は60秒の溜め（`$HOLD_SEC`）に入り、04:28:02 に**一本へまとめて**出された。
まとめる段の `Flush-Held`（L818〜）が、名乗りまで**最後の一本**のものを使っていた。

```powershell
$last1 = $held[$held.Count - 1]                                   # ＝ ready の側
[void](Send-NtfyNow $last1.title $body $last1.prio $last1.tags $last1.state)
```

**押し送りが出るかどうかは名乗りだけで決まる**（見分けを一箇所に閉じ込める決め）ので、
**押し送りの出る一本が、出ない一本に後ろから消された。**

**パネルには札が立つのに iPhone が鳴らない**という、いちばん気づきにくい形になる。
控えの側（`notices.json`）は `Record-Notice` が別に書くので、そちらは無事だった。

＊この穴は**写せます-1（`ready` を足した回）で生まれた**もので、通知の題-1〜4 とは関係ない。
　`ready` が押し送られないことは通知の題-1 の報告に書いたが、
　**「一緒に溜まった done まで巻き添えにする」**ところまでは見ていなかった。

## 3. 直し

`~/.claude/watch-notify.ps1` **L866-885**。まとめて出すとき、
**名乗りは溜まっている中の「いちばん強い一つ」を採る**。

```powershell
# 強さの順 … over（延び）＞ wait（ヨシ待ち）＞ done（終わり）＞ それ以外
$rank = @{ 'over' = 3; 'wait' = 2; 'done' = 1 }
$state = $last1.state
$best = 0
foreach ($h in $held) {
  $s = [string]$h.state
  if ($rank.ContainsKey($s) -and $rank[$s] -gt $best) { $best = $rank[$s]; $state = $s }
}
if ($state -ne $last1.state) { Write-Self ('名乗りは「' + $state + '」を採る（最後の一本は「' + … + '」）') }
…
[void](Send-NtfyNow $last1.title $body $last1.prio $last1.tags $state)
```

**題・重み・印は今までどおり最後の一本のもの。** `Push-Ntfy` は題を見ないので、
名乗りだけ差し替えれば足りる。差し替えた回は記録に残る。

＊`over` と `wait` は `$HOLD_NOW` で待たせない決めなので、ふだんここへは来ない。
　来たときに取りこぼさないよう順だけ書いてある。

### 直した選び方を、六通りで確かめた

| 溜まった並び | 直す前の名乗り | 直した後 | 押し送り |
|---|---|---|---|
| **`done` → `ready`（04:28 に起きた並び）** | `ready` | **`done`** | **出る**／題「😽 終わったにゃ、写して」 |
| `ready` → `done` | `done` | `done` | 出る／題「😽 終わったにゃ、写して」 |
| `done` 一本だけ | `done` | `done` | 出る／題「😽 終わったにゃ、写して」 |
| `ready` 一本だけ | `ready` | `ready` | **出ない**（今までどおり） |
| `done` → `dup` → `ready` | `ready` | **`done`** | **出る**／題「😽 終わったにゃ、写して」 |
| `done` → `wait` | `wait` | `wait` | 出る／題「😼 ヨシ頼むにゃ」 |

**`ready` 一本だけのときは今までどおり出ない。** 巻き添えだけを止めてある。
