## 1. 待ちの形ごとの比べ

見送るかどうかは「ロンの点 R」対「この先ツモで四暗刻になる率 P × 32000 −（押し続ける間の放銃・被ツモの損）」の比べ。
損を除いた分かれ目は **P ＝ R÷32000**（満貫8000で25%・跳満12000で37.5%・倍満16000で50%）。

| 形 | ロンで上がると | ツモで上がると | 決め |
|---|---|---|---|
| 暗刻4＋単騎 | 四暗刻単騎（core は `**`＝複合ありで二倍役満） | 同じ | **必ず取る**（今の norn と同じ） |
| 暗刻3＋対子2（シャンポン） | 三暗刻＋対々和＝4翻・50〜60符＝**満貫8000**（子）。役牌・断幺・ドラが2つ乗れば跳満12000、ドラ暗刻などで倍満16000 | 四暗刻32000 | **ここだけが見送りの分かれ道** |
| 暗刻3＋対子1＋塔子（孤立2枚が隣り合った聴牌） | 三暗刻だけ＝2翻（2600〜3200） | 三暗刻＋ツモ（役満にならない） | どちらで上がっても役満は消える。一向聴からの四暗刻ツモは中盤で一割に届かない見積もり＝**取る** |
| 暗刻3＋対子1＋孤立2（一向聴） | 和了の形でない | — | 対象外 |

シャンポンの P の出し方（一つの式）：見えていない待ち牌 u 枚・見えていない牌 N 枚・自分の残りツモ d 回・一巡ごとに局が他家の和了で終わる率 h とすると
p＝u÷N、x＝(1−p)(1−h)、**P ＝ p(1−h)(1−x^d)÷(1−x)**。
ロンの牌が出た時点で、その一枚はもう見えているので **u は多くても3**。

| 場面（N=100 と置く） | P | P×32000 | 満貫8000 と比べて |
|---|---|---|---|
| u=3・残りツモ15（3巡目あたり）・立直なし（h=0.04） | 約27% | 約8800 | 少し上＝見送る |
| u=3・残りツモ12（6巡目あたり）・立直なし | 約24% | 約7700 | ほぼ同じ＝取る側 |
| u=2・残りツモ12・立直なし | 約17% | 約5400 | 取る |
| u=3・残りツモ12・立直あり（h=0.15） | 約13% | 約4200 | 取る（しかも放銃の損が乗る） |

＝**点棒で見ると、見送りが得なのは「序盤・待ち3枚・立直なし・ロンが満貫止まり」の狭い場面だけ**。全部見送る norn は役満の率は上がるが、点棒は push と同じかそれ以下になる見込み。h の 0.04／0.15 は仮置き（一段目の tsv の「巡目」「結果」から base の腕で引き直せる）。

＊一段目で base（立直する・ロンも取る）が push より役満が多い（30.1% 対 21.7%・終局の巡 8.0 対 5.7）のは、立直で機械打ちが降りてロンの牌が出にくくなったためと読める（未確認）。黙聴は当たり牌が早く出て、安手のロンで局が閉じる。

## 2. 取る条件の案

| 案 | 決め | 長所 | 短所 |
|---|---|---|---|
| 甲：常に見送る（今の norn） | 単騎以外のロンは全部見送る | 役満の率の上限が出る。実装済み | 終盤・待ち1枚・立直を受けた後も見送る＝満貫を捨てて放銃を拾う。点棒は落ちる見込み |
| 乙：敷居で切り替える | 見送るのは「立直者なし・u が3・残りツモ13回以上（5巡目まで）・ロンが満貫以下」の時だけ | 人に言える一行になる（助言の字にしやすい）。隠れた数が無い | 敷居（5巡・3枚）は見積もりから置いた数。跳満・倍満の境目や2枚待ちの序盤を一律に扱う |
| 丙：期待値で比べる | 上の式で P を出し、P×32000 ＞ R＋押しの損 の時だけ見送る | 形・点・巡・立直・待ちの枚数を一つの式で扱う。敷居が式から出る | h と押しの損が仮置き。外れていれば結論もずれる。人に言う一行にはそのままならない |

## 3. 推す案

**丙（期待値で比べる）**。理由：見送りが得な場面は狭く、点・巡・待ち枚数・立直の四つが同時に効くので、一つの敷居より式で切る方が外しにくい。乙は丙の結果を人の言葉に直す時の形として、同じ走りに腕で並べる。

## 4. 実装（`YakuAI.select_hule` の中・疑似コード）

```js
select_hule(data, hupai, info) {
  const arm = this._ctx.arm;
  if (!this._yaku || !data || ['norn','nornT','nornEV'].indexOf(arm) < 0) return super.select_hule(data, hupai, info);
  if (data.m) return super.select_hule(data, hupai, info);            // 槍槓は元のまま
  const d4 = ['', '+', '=', '-'][(4 + this._model.lunban - this._menfeng) % 4];
  const rongpai = data.p.slice(0, 2) + d4;                            // 元の select_hule と同じ組み方
  const left = this.shan.paishu;                                      // 山の残り
  const r = Majiang.Util.hule(this.shoupai, rongpai, { rule: this._rule, zhuangfeng: this._model.zhuangfeng,
    menfeng: this._menfeng, hupai: { lizhi: 0, haidi: left === 0 ? 2 : 0 }, baopai: this.shan.baopai,
    fubaopai: null, jicun: { changbang: 0, lizhibang: 0 } });
  if (!r || !r.defen) return false;                                   // 和了の形でない・役なし
  if (r.damanguan) return super.select_hule(data, hupai, info);       // 単騎＝役満は必ず取る
  if (arm === 'norn') return false;                                   // 甲
  const sp = this._suanpai, lz = riichiSeats(sp, this._menfeng).length;
  let u = 0, N = 0;
  Majiang.Util.tingpai(this.shoupai).forEach(p => { u += sp._paishu[p[0]][+p[1] || 5]; });
  ['m','p','s','z'].forEach(s => { for (let n = 1; n <= (s === 'z' ? 7 : 9); n++) N += sp._paishu[s][n]; });
  const d = Math.floor(left / 4);                                     // 自分の残りツモ
  let skip;
  if (arm === 'nornT') skip = (lz === 0 && u >= 3 && d >= 13 && r.defen <= 8000);          // 乙
  else { const h = lz ? 0.15 : 0.04, p = u / N, x = (1 - p) * (1 - h);
         const P = d > 0 && u > 0 ? p * (1 - h) * (1 - Math.pow(x, d)) / (1 - x) : 0;
         skip = P * 32000 > r.defen + (lz ? 1500 * Math.min(d, 6) : 0); }                  // 丙
  return skip ? false : super.select_hule(data, hupai, info);
}
```

## 5. 雲で比べる腕の組と読み方

- **腕**：push（全部取る）／norn（甲）／nornT（乙）／nornEV（丙）／base。fold は四暗刻の枠では push と同じ数になるので外す。
- **枠**：s32（暗刻3＋対子2）と s31（暗刻3＋対子1）の二つに絞る。見送りの差が出るのは聴牌が近い枠だけで、五枠のままだと一腕 約230局＝幅 ±5pt で腕どうしの差が埋もれる。二枠×五腕なら一本で一腕 約400局。差が ±3pt に入るまで二本（通しの表で足す）。
- **読み方の注意**
  - 役満の率と点棒は逆を向きうる（norn は役満が増えて点棒が増えない見込み）。**二つを並べて読む**。どちらを「腕の良さ」とするかは測りの外の決め。
  - 点棒は32000で幅が広い＝腕どうしは「同じ山どうしの差」で読む。norn 系どうしの差（nornEV − norn・nornEV − push）の欄も要る。
  - 同じ山でも、最初にロンを見送った所から先は別の局になる。見送りの回数（何局で見送りが起きたか）を一列足すと、差の出どころが読める。
  - 機械打ちは聴牌即立直・こちらの黙聴を警戒しない・見送りを見ても打ち方を変えない＝ロンの牌は人の卓より出やすく、見送りの値打ちは人の卓より低めに出る。
  - 丙の h と押しの損は仮置き。丙が乙・甲に負けたら、式でなく置いた数を先に疑う。
  - 子の一席・一局だけ・順位なし。base は「狙わない席」ではなく、立直もする元の機械打ち。
