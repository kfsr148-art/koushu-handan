## ① 押すたびに機械が確かめる形

`check.yml` の `paths` へ `panel.html`／`panel-check.js` を追加し、ウィジェットの検査の後ろに
`- name: 返事パネルの検査（panel-check.js）` の段を入れた。手元でも `node panel-check.js` で同じものが回る。

やり方は作法14「写しに probe」。`panel.html` を一時ディレクトリへ写し、`fetch` を作り値へ差し替えて
headless で駆動する。**本体には一片も残さない。** 額縁は毎回その場で較正する（幅+24／高さ+92 と実測）。

## ② 見る中身（六つ）と、途中で直した二つの抜け

| | 何を見るか | いまの実測 |
|---|---|---|
| ① 構文 | `<script>` の塊が読めるか | ✓ 1件 |
| ② 四通り | 作業中／次の指示待ち／ヨシ待ち／異常 | 前三つ ✓／**異常は裁定待ち**（下記） |
| ③ 束ね | **作り値の札の数 ＝ 釦の「残N」 ＝ 実際に写った数** | ✓ 5件＝5件＝5件 |
| ④ 視野 | iPhone の横と縦（667x375／844x390／390x844） | ✓ どれも溢れなし |
| ⑤ 札の高さ | 題の長短で変わらないこと **＋ 固定した高さそのもの** | ✓ 79px＝79px（固定79px） |
| ⑥ 終了予定 | ウィジェットと同じ計算（開始＋見込み・過ぎたら見込みの幅で先送り） | ✓ 一致 |

**直した抜け（最初の壊しの実測で見つかった）**

- **③は物差しが二つでは足りなかった。** 「釦の残N」と「実際に写った数」は**どちらも同じ関数**
  （`buildBundle()`）を見ているので、束ねる側が一種類を落とすと**両方いっしょに減って辻褄が合う**。
  → **作り値の札の数**という第三の物差しを足した。
- **⑤は長短の比べだけでは足りなかった。** 高さの固定を外しても、短い題も長い題も**同じだけ縮む**ので
  差が出ない。→ 字面の `min-height` を読み、**その値そのもの**とも突き合わせる形にした。

## ③ わざと壊した作り値（本体には触らず、写しを壊して検査に掛けた）

| 壊し方 | 終了コード | 落ちた項目 |
|---|---|---|
| **(甲) 束から一種類を落とす**（延びの札を束ねない） | **1** | 「作り値は 5件…なのに、束ねたのは 4件。種類を落としている疑い」 |
| **(乙) 高さの固定を外す** | **1** | 「黄色の行に高さの固定（min-height）が無い」 |
| **(丙) 終了予定の式をずらす**（+7分） | **1** | 「終了予定が合わない（欲しい『16時44分終了予定』／出た『…16時51分終了予定…』）」 |
| (丁) いまの姿 | **0** | 通った |

＊直す前の検査では (甲)(乙) が**通ってしまっていた**。壊して初めて分かる抜けだったので、
　「壊してみる」を実測に入れておいて良かった一例として残す。

## ④ 真似た台では拾えないもの（検査の末尾に毎回書き出す）

- 公開側の遅れや詰まり（ここでは作り値が即座に返る）
- **iOS Safari 固有の描き方**（折り返し・字送り・慣性のある送り）
- 実機の触り心地（押しやすさ・二本指の送り）と、**写しがクリップボードへ本当に入るか**
- ntfy の押し通知そのもの

## 裁定をお願いしたい一点 — 「異常」がパネルに出ない

`state.json` の `stat` が **異常** のとき、いまのパネルは**画面のどこにも異常を出さない**。実測で確かめた。

- 黄色の行（`stateLineText`）は **作業中／次の指示待ち／ヨシ待ち の三通りだけ**。異常は空を返す
- 異常の**札**は `#list` に入るが、**v97 で一覧ごと畳んである**
- 状態の札（`#state`）は **v102 で畳んだ**

実測（`stat:'異常'`＋🪟 の札を与えた画面の字）… `まとめて写す（残2／2件）` ／ `直近に終わった仕事（0件）` ／
`本体 v1435 ／ stable v1434` ／ `最終確認 16:06` — **異常の手掛かりは一つも出ていない**。

**どう見せるかは設計の分かれ道**なので、こちらでは決めていない。検査では**落ちに数えず**、
毎回「異常：いまのパネルは画面に出さない（**裁定待ち**）」と書き出して忘れないようにしてある。
案としては (a) 黄色の行に四つ目として「異常です」を出す／(b) 異常の札だけ畳まずに出す／
(c) ウィジェットに任せてパネルは今のまま、のいずれか。
