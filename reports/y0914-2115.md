## 宣言① 現場猫の角-1 ／ 兎の角-1（v1442）

投票欄の丸い枠は `.verdict-zones .vz-face`（L303）の `border-radius:50%` が、
**絵を持つ九人**（人柄七人・兎・現場猫）へ一括で掛けている。この行は触らず、
`data-who="cat"` と `data-who="usagi"` に限った上書きを足して、**その二つだけ角を落とす**。

枠の大きさ（見た目40px・当たり判定44px・間隔8px・箱の最低の高さ48px）は変えないので、
**並びの高さも他の顔の位置も動かない**。人柄の釦の列（`.eye-btn`）と見立て行の頭（`.say-icon`）は
別の指定なので、今のまま。

### 裁定してほしい一点 — 「原寸のまま伸縮なし」

絵の実寸を数えた。**現場猫 `CAT_TILE_GENBA` は 480x480、兎 `USAGI_IMG` は 178x400。**
どちらも本体に data URI で埋まっている（リポジトリの `genba-cat-*.png` は `panel.html` だけが使う）。
40pxの枠に対して **12倍と10倍**で、兎は正方形ですらない。

| | やり方 | どう出るか |
|---|---|---|
| 甲 | `object-fit: none`（字義どおりの等倍） | 480や400の絵の**中央40x40画素だけ**が出る。猫も兎も顔が写らない |
| 乙 | 40px角へ焼き直して埋める | 新しい絵を作って data URI を差し替える工事になる |
| **丙** | いまの `object-fit: contain` のまま、**角だけ四角に** | 480→40 は**ちょうど1/12**、兎も等比で歪まない。`image-rendering:pixelated` が既に効いているのでにじまない |

**丙を推す。** 頼まれた「四角い枠・角は丸めず・歪めず・にじませず」は丙で全部満たせて、
絵を焼き直さずに済む。

## 宣言② 釦の押せ-1（v1443）

**枝豆と紳士が押せない理由を突き止めた。** `toolEyeSay`（L4768）が
`window._edamameNote` ／ `_shinshiNote` だけを見ており、この二つは

1. 特別ルームのスイッチが `localStorage` で **ON** の回、かつ
2. その物差しが**口を開く帯**で、かつ
3. **本判定と食い違わない**回

の三つが揃った時にしか立たない。**食い違う回は `window._vzMiss` へ回る**ので空のまま。
現場猫も同じ作りだが 0枚／4枚以上でよく立ち、兎は `window._lastCut` を見るので常に立つ——
**押せる二つと押せない二つの差はここ**だった。

**直し** … `toolEyeSay` の二行を「**控えが空なら投票欄の文（`window._vzSay`）へ落ちる**」形にする。
投票欄の文は `tenLeans` が毎回必ず添えているので、四つとも必ず押せるようになる。
入れ替えと二度押しで戻る仕掛けは今のまま使うので、**見立て行は一行のまま高さが変わらない**。判定には触れない。

## 宣言③ 釦の押せ-2（v1443 に同梱）

`tenLeans` は**票を出さない回でも `say` を作っており**、`window._vzSay` には十一人ぶん全部が入っている。
ただし**黙る帯の `say` は言い切ってしまう**（猫牌3枚でも「猫牌3枚、指差し確認——逃げヨシ！」）。
そのまま出すと黙る帯で守りを断じることになるので、**黙る帯だけは数えた枚数の一行へ差し替える**。

| 目 | 口を開く帯 | 黙る帯 |
|---|---|---|
| 現場猫 | 猫牌0枚／4枚以上 … 今の文 | 1〜3枚 … 「猫牌N枚——この帯は判定に回す」 |
| 枝豆 | 常に文がある … 「N種。揃い」「N種。薄い——守り」 | （無い。落ちるだけで足りる） |
| 紳士 | 一枚きりの字牌0枚（么九2枚以下）と3枚以上 … 今の文 | 1〜2枚 … 「一枚きりの字牌N枚——この帯は判定に回す」 |
| 兎 | 切る候補があれば「切るなら〈牌〉」 | 無ければ「弱い余りN——この帯は判定に回す」 |

**言葉づかい一点** … 頂いた例は「🐱猫牌3枚——この帯は判定に回す」だが、本体の決めは
**文頭に絵文字を付けない**（話者の印は見立て行の行頭アイコンが持つ。L8511 の註）。
この決めに合わせて**絵文字なし**で入れるつもり。付ける形がよければヨシの時に一言ください。
