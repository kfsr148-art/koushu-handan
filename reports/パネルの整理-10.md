## 2. 右側は説明の分だけ。印は左に一度

件名を割るのは `splitSubj()`（**L637-659**）。

```js
function splitSubj(t) {
  var s = String(t || '').trim();
  if (!s) { return { mark: '', rest: '' }; }
  var m = s.match(/^([^（(\s—]+)\s*(?:（([^）]*)）)?\s*(.*)$/);
  if (!m || !m[1]) { return { mark: '', rest: s }; }
  var inner = m[2] || '';
  var tail = (m[3] || '').trim();
  var rest = (inner + ((inner && tail) ? ' ' : '') + tail).trim();
  rest = rest.replace(/^[—–ー-]\s*/, '');   /* 頭に残った繋ぎのダッシュは落とす */
  return { mark: m[1], rest: rest };
}
```

**割り方を五通りで確かめた。**

| 件名の形 | 左（印） | 右（説明） |
|---|---|---|
| `パネルの整理-8（お知らせを消し、黄色の行を固定位置へ）— panel v97` | `パネルの整理-8` | `お知らせを消し、黄色の行を固定位置へ — panel v97` |
| `パネルの整理-9`（印だけ） | `パネルの整理-9` | **（空）** |
| `v1429 — 副産物三件を本体へ当てた（…）` | `v1429` | `副産物三件を本体へ当てた（…）` |
| `写しの一回-3 読み返しをやめる`（括弧なし） | `写しの一回-3` | `読み返しをやめる` |
| （空） | （空） | （空） |

**説明が無い件名は右を空にする。** 印を左に出すので、右へ同じ字をもう一度出さない。
**割れない形のときは印を空にして全部を右へ回す**（今までどおりの姿になる）。
