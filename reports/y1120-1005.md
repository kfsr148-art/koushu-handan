# 手伝いの数を background_tasks だけで数える（2026-11-20 10:30）

## 直前の穴
- 手伝いの数は SubagentStart／SubagentStop の足し引き（busy.txt の agents）だった。SubagentStop は手伝いを止めた時や不具合の続く時に鳴らない事がある（#92716・#78463）。数が残ると「裏で手伝い N本」で作業中のまま、札が永久に出ない。

## 直したこと
1. **数え方を一つに**：`help-count.js`（リポジトリ直下）。Stop の入力の background_tasks（turn-mark.js が busy.txt の bg に写す）を正にする。窓が手待ち（Stop・idle_prompt・StopFailure・Interrupted・EndTurn）で、一覧が無い・空なら 0。手番が開いている間は数えない（作業中は合図の足跡で決まる）。一覧の後に手番が開いたら前の一覧は使わない。30分たっても次の Stop が無い一覧は「不明」。teammate は数えない。
2. **足し引きをやめた**：turn-mark.js から agents の足し引き・agentEnd・会話の記録読みを全部外し、busy.txt の agents・help は書かない（残っていれば消す）。settings.json の SubagentStart／SubagentStop の hook 4本（turn-mark・turn-push）を外した（Stop の約2〜7秒後に鳴って「最後の合図」を Stop から SubagentStop に上書きし、input-stall の手待ち判定を乱す元でもあった）。
3. **同じ値を読む所**：
   - 札の書き手・パネル：state-decide.js（help-count を使う）。待機中でなければ札を出さない、パネルの help／検査中・待ちの字は同じ値。
   - 再起動の見送り：reboot-hold.js（手伝い＋裏の命令を理由にする）。
   - 空回りの止め：stop-steps.js（手伝いが走る間は block しない）。
   - 起こし役：rewake.js（窓が手待ちの間だけ数える）。

## 作り値
- 状態の決め所の総当たり（state-decide-test.js）：960組 NG 0件。足し引きの agents（AG）は居ても数えない形に期待を直した。
- 手伝いの数 12件 合い：一覧が空→待機中／一覧が無い→待機中／**agents が残っていても数えない**→待機中／一覧に手伝い1本→作業中／Stop の約60秒後の idle_prompt でも数え続ける／手番が開いたら前の一覧は使わない／手番の中は数えない／30分前の一覧→「手伝い 不明 1本」で待ち／teammate を外す。
- 実動作（偽の置き場・turn-mark・reboot-hold・state-decide）11件 PASS：Stop の一覧が bg に写り agents・help が消える／SubagentStart・Stop が来ても agents を作らない／stop-steps・reboot-hold・rewake は help-count を使い agents を読まない／reboot-hold は一覧1本で見送り・空なら理由にしない／state-decide と reboot-hold が同じ値。
- 直す前の state-decide は、同じ入力（Stop・agents が残る・一覧なし）で「作業中・裏で手伝い1本」のまま。直した後は「待機中・空」。
- 本物の busy.txt：次の合図で agents が消え、bg の一覧は空になった（state.json の help も空）。

## 実機で見る所
- 手伝いが残ったままの「裏で手伝い N本」が出なくなる。手伝いが本当に走っている間は、Stop の後に「作業中（裏で手伝い1本）」が出て、止まれば自分で消える。
