# 黒猫の待機-2 — ヨシ待ちの猫が地に沈む件

**結論：黒版は地に沈んでいた（比 1.07）。白版へ戻した。焼き直しは要らなかった。**

## ① 測った — 黒版と地のコントラスト比

地は `panel.html` の `--bg:#14241c`（RGB 20,36,28）。式は WCAG（相対輝度＋0.05 の比）。
透過のある画素は**地の上に重ねた色**で測った。

| | 寸法 | 不透明な画素 | 一番濃い画素 | 地との比 |
|---|---|---|---|---|
| `panel-icon-black.png` | 164x152 | 8,642 | RGB(27,27,27) a=255 | **1.07** |

影絵なので色は一種類しかない（8,642画素すべて RGB 27,27,27）。**濃い方も淡い方も同じ 1.07。**
3.0 を大きく下回る——**地とほとんど区別が付かない**。

## ② 白版は焼かずに済んだ

`panel-icon-white.png` は既にリポジトリに在り、**黒版はこの白版から色だけ塗り替えて焼いた物**
（`cat-black.js`：alpha はそのまま、RGB だけ #1b1b1b にする）。実測でも一致した。

```
透過（alpha）の突き合わせ  黒版 vs 白版
  画素数 24,928 ／ 食い違った画素 0 ／ 最大の差 0
  → 完全に一致（形・余白・透過の扱いは同一）
```

寸法も 164x152 で同じ、不透明な画素も 8,642 で同じ。枠の条件（**寸法・余白は黒版と同一。
透過の扱いも同じ**）を既に満たしているので、**焼き直していない**。

| | 一番濃い画素 | 地との比 |
|---|---|---|
| `panel-icon-white.png` | RGB(255,255,255) a=255 | **16.17** |

＊同じ名で焼き直さないのは作法21（「同名での作り直しを禁じる」）にも適う。

## ③ 向き先を白版へ

`runCatTick` の**ヨシ待ちの枝だけ**を差し替えた。

```js
if (lastStat === 'ヨシ待ち') {
  catAwake = false;
  if (el.src.indexOf('panel-icon-white') < 0) { el.src = 'panel-icon-white.png'; }
  return;
}
```

先読みの一覧にも足した。

```js
catFrames.concat(['cat-sleep.png', 'panel-icon-black.png', 'panel-icon-white.png'])
```

**触っていないもの** … 作業中のコマ送り（`cat0〜4`）／`cat-sleep` の寝姿／その他の枝。
