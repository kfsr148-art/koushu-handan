## 1. 型の選び（機械の既定）と訳

**全部「イ（数と訳を言う型）」にそろえる。** 理由は三つ。
- 本人が選んだ言い方「2回続けて切れる」を使えるのは、イだけ（ロは元の「一巡勝負」・「と言われる」の薄い元、ハは「1と9と字牌に寄せる」で、元の訳と守りの結びが一部こちらの組み立て——報告 y1122-1330 の五）。
- イは定石の断言（「〜と言われる」）を使わず、配牌の13枚から言える事（対子の数・2回続けて切れる）だけで成り立つ。
- 分けごとに型を変えると id が増える（声の枚数・口調の突き合わせが増える）。

| 分け | 種を出すか | 型・出し方 | 一行の訳 |
|---|---|---|---|
| pair（対子が多い） | 出す（盾の一文だけ） | イ：`advd-w-chi-t` のみ | 訳の行（advd-w-pair）が既に「対子が多い」と言うので、数の一文（chi-n）は重ねない |
| few（安全牌が少ない） | 出す | イ：`advd-w-chi-n` ＋ `advd-w-chi-f` | 盾が無い手で、対子が安全牌の代わりになる、と言う |
| shape（形が悪い） | 出す | イ：`advd-w-chi-n` ＋ `advd-w-chi-t` | つながらない手でも、対子は盾として残る、と言う |
| far（手が遠い）・cheap（安い） | 出す（同じ字） | イ：`advd-w-chi-n` ＋ `advd-w-chi-t` | cheap は本体で `w='cheap'` に分かれるが、種は同じ字で足りる（報告の三と同じ扱い） |
| honor（字牌や端が多い） | **出さない** | — | 盾はもう足りている。「字牌の対子」のひと言（advd-s-jihai 系）と重なる |
| 九種九牌（`a.kyushu`） | **出さない** | — | 「流す」と言う分け |

## 2. 出る条件

**`F.pairKinds >= 3`**（対子が3組以上・同じ牌が2枚以上の種類の数）。
【読】`F.pairKinds` は `koushu-handan.html` の `toneFacts` 内（3402行付近：`pairKinds: vals.filter(function(c){ return c >= 2; }).length`）で作られ、守りの分けの決めにも `else if(F.pairKinds >= 3) w = 'pair';`（3476行付近）として既に使われている。守りの枝（`advLines0` の守り）の中で `F` が見えていることも読んで確かめた。
注：刻子（3枚）も1組に数える（pair の分けと同じ数え）。文は「3組以上」と言うので、実際の組数が5でも嘘にならない。数の部品（{p}）は使わない＝新しい声の部品を作らずに済む。
条件に使わない物：`F.pairs2`（ちょうど2枚の組）。本人の決め「対子3組から」と pair の分けの条件を揃えるため、`pairKinds` を採る。

## 4. 差し込む場所（一意の字面で grep できる）

【読】本体と核は同じ字面を二か所に持つ（check.js が突き合わせる）。核が正本。**本体は別の枠が編集中なので、行番号は目安・必ず字面で探す。**

1. **行の定義**（核・本体の両方）：`advRow7("advd-s-jihaio", [` の行の直後に、`advRow7("advd-w-chi-n", [...])`・`advRow7("advd-w-chi-t", [...])`・`advRow7("advd-w-chi-f", [...])` の三行を足す。
   - 核：`advice-tone-core.js` 1139行付近／本体：`koushu-handan.html` 3165行付近。
   - 直前のコメントに一行足す（v番号・枠・何の種か）。
2. **種を出す所**（本体だけ・`advLines0` の守りの枝）：字面 `if(l2.length > 0) lines.push(l2);`（本体 3490行付近・一意）の**直後**に、次を足す。
   ```js
   if(!a.kyushu && F.pairKinds >= 3 && w !== 'honor'){
     lines.push(w === 'pair' ? ['advd-w-chi-t'] : w === 'few' ? ['advd-w-chi-n', 'advd-w-chi-f'] : ['advd-w-chi-n', 'advd-w-chi-t']);
   }
   ```
   - 置く順は 訳 → 切る順（l2）→ **種** → ひと言（`advd-s-*`）→ 線 → リーチ。
   - **「訳と切る順の間」には置かない。**【読】`advEchoLs`（核 1281行付近）が訳の次の行（`o[1]`）の頭に「遠いので、」「安全牌が少ないので、」の受け直しを付ける。種を `o[1]` にすると、その受け直しが種の頭に付いてしまう。l2 の後ろなら、受け直しは今までどおり切る順の行に付く。
   - `F.pairKinds >= 3` の手では `keep`（対子の牌）が必ず空でないので、l2 も空にならない【読】（`keep` は字牌と2枚以上の数牌から作られる）。
3. **詰めの段で外す**（核・本体の両方）：`function advDropSLs` の正規表現 `/^advd-s-(soba|nito|ukai|jihai)/` の行に、`advd-w-chi-` も外す印として足す（例：`/^advd-(s-(soba|nito|ukai|jihai)|w-chi-)/`）。声が30秒に収まらない時、ひと言添えと同じ段で種を落とせる。
   - 【仮】これを足さないと、収まらない時に種だけが残って他の物が先に削られる。足す方が安全。
4. **足さなくてよい所**：`ADV_SHORT_SRC`（短い版は作らない）／`ADV_KIND`（`advd-w-.*` で⑤に当たる）／`ADV_OMO_OVERLAP`（面白みの一言との重なり表。種は対象外）／`ADV_ECHO`（受け直しは訳の行だけ）。
