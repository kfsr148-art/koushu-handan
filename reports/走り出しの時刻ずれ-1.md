# 走り出しの時刻ずれ-1 — 「22時58分」は**前の仕事の開始 ＋ いまの見込み**だった

**状態：終わり（実地の見届けは次の走り出しを待つ）／本体（`koushu-handan.html`）には触っていない**

**結論** — 足し算そのものは正しい。**材料の刻が前の仕事のもの**だった。
`work-started.txt`（開始の刻）は仕事が替わってから**十数秒あとに**書き換わるので、
その隙に鳴ると **前の仕事の開始 ＋ 新しい見込み** を足す。**日を跨いだ計算の狂いではない。**
数字を出さず「未定」と鳴らす安全側の枝を足した。

## ② 名指し（三つの疑いを一つずつ）

- **見込みの読み方がずれたか** … ずれていない。`見込み: 40分` を 40 と読んでいる。
- **前の日の値を引きずったか** … **これ。** 引きずったのは見込みではなく**開始の刻**。
- **日を跨ぐ計算で狂ったか** … 狂っていない。エポック秒どうしの足し算で、日付は関わらない。
  22:58 という刻も「前日22:18＋40分」として正しく出ている。

**黙り-2 の直しとの関わり** — 直しが**この型を生んだのではない**が、**出やすくした**。
v1 は「見込みのある回だけ鳴らす」作りで、印は `件名＋開始` だった。直しで
「見込みが無くても鳴らす」「印に形（time/undef）も入れる」ようにしたため、
**仕事が替わった直後の、材料が揃っていない一瞬でも枝へ入る**ようになった。
同じ型は直し**前**にも出ている——**2026-09-01 22:18:20 の「😸 終了予定は21時41分ですにゃ」**が
それで、開始 21:14:29（前の仕事）を使って**いまより前の刻**を出していた。

## ③ 直し — いまより前・遠すぎる先なら数字を出さない

```
$startForm = 見込みがあれば time／無ければ undef
  ＊出す刻が いまより前          → 形を undef へ落とす（理由を記録に残す）
  ＊出す刻が いまから12時間より先 → 同上
題を分けるのは **$startForm**（$ovMin ではない）
```

＊**題の分け方を `$ovMin` のままにすると、伏せたはずの刻がそのまま題に出る。**
作り値で実際に出たので直した（下の一度目の実測）。物差しは `$START_FAR_H = 12`。

＊刻が揃った次の巡回で、形が undef → time へ変わり、**時刻つきで鳴り直す**（黙り-2 で入れた
　繰り上げの道がそのまま効く）。**知らせが消えるのではなく、正しい刻へ言い直す**形になる。

## ④ パネルの黄色の行も同じずれを持っていた

`state.json` の `startedAt ＋ 見込み` をそのまま足しており、**同じ材料なら同じ 22:58 を出す**。
同じ12時間の物差しを入れた（**panel v107**）。二箇所で違う物差しを使わないよう、
`FAR_SEC = 12 * 3600` を一箇所に置いてある。

**いまより前の刻は、パネルでは伏せない。** 超過して走っている回の終了予定は過去になるのが
正しく、経過の分と並べて読むために要るため。**伏せるのは先へ飛んだ刻だけ**にした。
