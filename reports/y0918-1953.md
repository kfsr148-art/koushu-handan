## ③ 二つの形を並べる

同じ窓（12:27〜19:58）で数えた。

| | 甲 いまのまま（打ち切る） | 乙 通し切る（打ち切らない） |
|---|---|---|
| 走りの本数 | **100本**（通った72・打ち切られた28） | **98本**（押しの数だけ） |
| 走りの合計 | **71分** | **51分**（一本31秒） |
| 公開の遅れ・中央 | 配信が通れば31秒 | **31秒** |
| 公開の遅れ・いちばん長い | **飢える**（今日は約6分一本も通らず・pub-late 37分） | **1.8分** |
| 公開に出る中身 | 常に最新（通ったときだけ） | **押しごとに順に**（最後に最新へ追いつく） |

**利と代償**

- **甲の利** … 中身が常に最新。無駄な配信をしない（つもり）
- **甲の代償** … 押しが36秒より短い間隔で続くと**飢える**。今日はその間隔が **24%**あり、実際に六分の穴と 37分の pub-late を生んだ。
  **打ち切られた28本は走った時間だけ捨てている**（317秒・141秒・134秒の三本を含む）
- **乙の利** … 飢えない。今日の列では**最長1.8分**、山の中でも80秒で追いつく。
  走りの本数も時間も**増えない**（100本71分 → 98本51分）——打ち切りで捨てていた時間が無くなるため
- **乙の代償** … 山の間は**古い中身を順に配る**（最後の一本で最新に追いつく）。
  押しが31秒より速く**長く**続けば列が伸びる（今日の最悪は1.8分だが、もっと長い山では伸びる）

＊どちらを採るかは**仕組みの分かれ道**なので、ここでは選ばず並べるまで（枠の決めのとおり）。
　数字の向きだけ一行 … **走りの本数も時間も増えないのに、飢えが消えて最悪が6分→1.8分になる**のが乙の測り値。
