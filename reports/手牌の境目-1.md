# 手牌の境目-1 — 746x375 の手牌が12px切れる件。境目は実測で 758px

**状態：終わり（残り0件）／VAIO 2026-08-31 23:2x ／ 本体には触っていない（案は実装していない）**

**結論** — 小型化なしの配牌枠（14枚）は **732px** 要り、枠の幅は「視野の幅 − 26px」なので
**収まる最小の幅は 758px**。いまの境目は 745px なので、**746〜757px の12px幅の帯で牌が切れる**。
案A（実寸に合わせて詰める）と案B（境目を757へ動かす）を写しの上で9視野ずつ測り、**どちらも溢れは消えた**。
**違いは牌の大きさ**——案Aは 746px でも牌36pxのまま隙間だけ詰まり、案Bは 757px まで牌30pxに縮む。

## ① 745 の作りと、収まるのに要る最小の幅

**幅745以下で切っている規則は二つ**（同じ数字を別々の理由で使っている）。

| 行 | 規則 | 何をするか |
|---|---|---|
| **1113** | `@media (orientation: landscape) and (max-width: 745px)` | 配牌枠の牌を **36×42 → 30×36**、隙間 **12 → 3px**、右余白 **23 → 6px**。見張り台の牌も 32×42・隙間2へ |
| **260** | `@media (max-width: 745px)` | 投票欄の見せ枠 `--vz-show` を **5.5 → 2.5** |

配牌枠は横向きでは `flex-wrap: nowrap` ＋ `overflow: hidden`（904行）。**折り返さず、切れても合図が出ない**。

**要る幅（実測）**

## ② 二つの案（写しの上で9視野ずつ実測）

### 案A — 実寸に合わせて切る（幅の固定値を使わない）

```css
@media (orientation: landscape) {
  .hand { gap: clamp(3px, calc((100% - 504px) / 13), 12px); }        /* 504 = 36px × 14枚 */
  .hand .tile { width: clamp(30px, calc((100% - 39px) / 14), 36px); } /* 39 = 3px × 13（隙間の下限） */
}
```

`100%` は枠の中身の幅（余白を除いた幅）。**まず隙間が 12→3px へ詰まり、それでも足りなければ
牌が 36→30px へ縮む**。1111行の注記「牌を縮めるより先に隙間と余白を削り、足りないぶんだけ牌を詰める」
という**元の設計の意図をそのまま連続にした形**。上限・下限はいまの二段（36/12 と 30/3）と同じ。

### 案B — 境目の数字を動かすだけ（745 → 757）

```css
@media (orientation: landscape) and (max-width: 757px) { …いまの1113行の中身のまま… }
```

**757 で切る**（758から収まるので、757までは小型化を効かせる）。`--vz-show` の 745（260行）は動かさない。
