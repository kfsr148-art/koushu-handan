# ヨシの猫を差し替え-1 — マス目の割り出しと、箱を上げる案

**マス目は割り出せなかった。この絵はマス目に乗っていない。**
そのため「マス数へ落とす」道は取れず、三へ進んだ。**実装はしていない。**

## 一、マス目の割り出し → **無い**

二通りで測った。どちらも「マス目がある」と言っていない。

### (甲) 枠の中が全部同じ色になる割合

一マス候補 k について、k×k の枠の中が全部同じ色である枠の割合。
**本当のマス目なら、その k で跳ね上がる。**

```
一マス  2px → 69.2%     一マス  8px → 55.5%     一マス 16px → 48.3%
一マス  3px → 64.7%     一マス 10px → 53.8%     一マス 20px → 46.0%
一マス  4px → 62.0%     一マス 12px → 52.1%     一マス 24px → 44.0%
一マス  5px → 59.6%     一マス 15px → 49.2%
一マス  6px → 58.1%
```

**跳ね上がりが一つも無い。**k が大きくなるほど滑らかに下がるだけで、
これは「マス目に乗っていない絵」の形。

### (乙) 色の変わり目が k の倍数に寄っているか

色の変わり目（横 10,238箇所・縦 11,693箇所）の位置を k で割った余りの偏り。
**マス目があれば、余りが一つの値に集まる。**

| 一マス | 偏り | | 一マス | 偏り |
|---|---|---|---|---|
| 2px | 1.02倍 | | 12px | 1.14倍 |
| 4px | 1.03倍 | | 16px | 1.27倍 |
| 5px | 1.09倍 | | 20px | 1.42倍 |
| 8px | 1.20倍 | | 24px | 1.45倍 |

**2〜20px はどれも 1.0〜1.4倍**＝ほぼ「ばらけたまま」。
（21px だけ 2.88倍だが、**480 は 21 で割り切れない**ので、これは測り方の綾で、マス目ではない。）

> **一マスが何画素かは決まらない。よって「480 を割った何マス四方か」も出せない。**

### 輪郭の太さ（これは測れた）

黒の横の連なりの分布 … **5px×333**／10px×154／4px×151／1px×129／6px×74。
**いちばん多いのが 5px、その倍の 10px が次**。中央値も 5px。

> **輪郭は約 5px の太さで描かれている**（ところどころ 2本ぶんの 10px）。
> マス目には乗っていないが、**細かさの下限は 5px** と読める。

## 二、落とせる限界 → **36pxには収まらない**

輪郭の黒が **1px 以上**残る縮め率は **1/5 まで**。

| 収める高さ | 縮め率 | 5px の輪郭が | |
|---|---|---|---|
| **96px** | 1/5 | **1.0px** | **残る** |
| 64px | 1/7.5 | 0.67px | 残らない |
| 48px | 1/10 | 0.50px | 残らない |
| **36px** | **1/13.3** | **0.38px** | **残らない** |

**36px では輪郭が残らない。ここで止めて三へ進んだ。**

＊参考の実測（36pxへ最近傍で落としたとき）… 残った画素 596 のうち黒は **133**。
　滑らかに落とすと 719 のうち黒は **49**。どちらも線として読めない。

## 三、箱の高さを上げる案（代償つき・実装はしていない）

写しに probe を差し、`#runcat` の高さだけ変えて測った（414x896・偽の `fetch`）。

| 猫の高さ | 余白 | ヘッダーの高さ | 最初の釦の上 | 36px からの差 |
|---|---|---|---|---|
| **36px（いま）** | `-3px 0` | **65.4px** | 69.4px | — |
| 48px | `-3px 0` | **77.0px** | 81.0px | **ヘッダー +11.6px ／ 釦 +11.6px** |
| 64px | `-3px 0` | **93.0px** | 97.0px | **ヘッダー +27.6px ／ 釦 +27.6px** |
| 96px | `-3px 0` | **125.0px** | 129.0px | **ヘッダー +59.6px ／ 釦 +59.6px** |
| （参考）36px | `0` | 71.0px | 75.0px | +5.6px |

**負の余白が吸っているのは 5.6px**（36px・余白0で 71.0px、`-3px 0` で 65.4px）。
9月8日に註へ書いた値と一致した。

**下の物は、ヘッダーが伸びたぶんそのまま下がる**（釦は +11.6／+27.6／+59.6 と同じ幅）。
＊黄色の行は、作り値では `fetch` を偽物にしているため中身が入らず、動きを測れなかった。
　釦と同じだけ下がると見てよい（同じ流れの中にあるため）。
