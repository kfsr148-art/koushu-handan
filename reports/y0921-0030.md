## 2. 26分の穴の訳と、23:45 の起こし直しの主

**穴は二段でできている。**

**① ログオンしていない17.5分（23:21:52〜23:39:25）** … `Claude*` の予定は全部
**`Logon Mode: Interactive only`**（ログオン中だけ走る）。だから電源が戻っても、
**人が画面に入るまで一つも走らない**。この間 **id=332 が56回**積まれている。
＊`ClaudeCodeAtLogon` は「ログオン時」の予定なので、これも同じところで待っている。

**② 立ったのに居座った6分（23:39:58〜23:45:29）** … ログオン直後に `ClaudeWatchNotify` は
走り出した（pid 6772）が、**記録を一行も書かないまま止まっていた**。起動直後の混みよう
（claude の立ち上げ・押しが20秒で時間切れ）で、入口の段に入る前で詰まっていたとみられる。
**同時に一つしか走れない**決めなので、後の毎分の起動は全部見送られる。

**23:45 の起こし直しは、常駐（`inbox-watch.ps1`）の手。**
23:45:29「**居座っていた見張りを落とした（pid 6772・6分）**」——常駐が居座りを見つけて殺し、
次の毎分の起動が通るようになった。続く 23:45:33 に「🪟 見張りが止まっています（26分前）」の札を立てている。
**この「26分」が、いま突き止めている穴そのもの。**

## 3. 「戻りました」の札が立たなかった訳

**四つ重なっている。**

1. **`ClaudeCodeAtLogon` は窓を開けるだけ。** 中身は
   `cmd /k claude.exe --continue --remote-control koushu-handan` で、**問いを渡していない**。
   窓は 23:39:53 に立ったが、**働き手は動かない**（`hook.log` に `resume` が入るのは 23:57:36）。
2. **「戻ったら札を出せ」という指示は、落ちた回の中にしか無かった。** 台帳には
   「再起動の稽古」の行が未了で残っていたが、**台帳を読んで動き出す仕掛けは無い**
   （常駐の起こしは、受信箱に未読の指示がある回だけ）。
3. **`after-reboot.ps1` は作ってあるが、繋いである先が週一の `ClaudeAfterReboot`（土 01:10）だけ。**
   起動やログオンには繋いでいないので、この稽古では一度も走っていない（最終実行＝無し・267011）。
4. **23:50:30 に「✅ 終わりました：再起動の稽古」が立ってしまった。** これは
   **落とす直前の控え**が札になったもので、読む側には「稽古は済んだ」に見える。
   戻りの点検が無いことに、札の側からは気づけない。

## 4. 切れた場所ごとの直し方と代償（**直しはまだしない**）

| 切れた所 | 直し方 | 代償 |
|---|---|---|
| **①ログオン待ちの17.5分** | 予定を**「ユーザーがログオンしていなくても実行する」**へ変える（`schtasks /RU` ＋パスワード保管、または SYSTEM で走らせる） | 画面に触れる仕事（窓を出す `ClaudeCodeAtLogon`・`send-esc.ps1`）は**この形にできない**。`SYSTEM` にすると人の持ち物（`~/.claude`）の道が変わる。パスワード保管は機械に鍵を置くことになる |
| 同上（別の手） | **自動ログオン**にして、電源が戻れば人無しで画面に入る | 機械が鍵無しで開く。持ち出す機械では採れない |
| 同上（軽い手） | 予定に**「起動時」の引き金**を足し、ログオン後の一発目を早める | ログオンしていなければ結局走らない（①の根は残る）。効くのは「ログオンが速い回」だけ |
| **②居座った6分** | 常駐の**居座りの敷居を6分から2分へ**縮める | 重い回の巡回を**途中で殺す**ことが増える。いまの敷居は「フル版の検査が回る回」を殺さないために広く取ってある |
| 同上 | 予定の**「X時間X分で止める」を10分から3分へ** | 同じ。長い段（押し・検査）を持つ回が切られる |
| **③戻りの点検が無い** | `after-reboot.ps1` を**起動時の予定にも繋ぐ**（`/SC ONSTART` ＋ 5分の遅らせ） | ①が直っていないと、ログオンするまで走らない。走っても**人の手の点検ではない**（四つを見るだけ） |
| **④働き手が動かない** | `ClaudeCodeAtLogon` に**問いを一つ渡す**（例：`claude -p "再起動から戻った。台帳の未了を読んで点検し、札を出せ"`） | **ログオンのたびに一回分の応答が走る**（使用量を食う）。窓を開けるだけの今と違い、**人が見ていない間に手が動く** |
| 同上（軽い手） | 常駐の起こしを**「台帳に未了があり、かつ最後の `resume` から30分以上」**でも起こす形にする | 手待ちの夜中に起き続ける恐れ。起こす条件を誤ると**同じ仕事を二度始める** |

**いちばん効くのは④**——①②を直しても、**戻ったことを誰も言わない**形は変わらない。
**いちばん危ないのも④**（人が見ていない間に手が動く）ので、ここは裁定を仰ぎたい。
