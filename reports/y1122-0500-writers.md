## 三、計算で出す案（panel-core.js・endat.js は触っていない・案だけ）

1. **段の欄を state.json の写しでなく、台帳の生の段から毎回計算する**
   - inbox-watch.ps1 が state.json に `"steps":{"job":"…","rows":[{"k":" ","t":"…"},…]}`（job-steps.txt の字のまま・state-decide.js の readSteps と同じ形）を一つ足す（~/.claude 側・直すなら次の枠で）。
   - panel-core.js 128行 `var tot = Number(o.stepTotal) || 0, dn = Number(o.stepDone) || 0, now = s(o.sNow).trim();` を
     `var st = stepsOf(o), tot = st.total, dn = st.done, now = st.now;` に替え、近くに
     `function stepsOf(o) { var r = (o.steps && o.steps.rows) || null; if (!r) { return { total: Number(o.stepTotal) || 0, done: Number(o.stepDone) || 0, now: s(o.sNow).trim() }; } var p = r.filter(function (x) { return x.k !== 'x'; }); return { total: r.length, done: r.length - p.length, now: p[0] ? s(p[0].t).trim() : '' }; }`
     を足す（生の段が無い古い state.json では今の欄へ落ちる）。174行 `omoteGauge` の呼び手も同じ stepsOf を使う。
   - こうすると turn-mark.js（sNow だけ書き替える）と inbox-watch（N/M も書く）の刻のずれが出ない。
2. **公開の版は段の字でなく実物から**：compare-dest.js が既に main と公開の panel-ver.txt を読んでいる（`panel` の組）。その値を compare-dest-state.json に `pubVer` として控え、inbox-watch が state.json の `pubVer` に写す。panel-core.js には「公開 v208（HH:MM に確かめ）」の一行を組む関数を足す（段の台帳の字「v208 を公開し直す」が残っていても、実物の版が出る）。
3. **endat.js 88行** `const st = Number(d.startedAt) || Number(d.statAt) || 0;` は今の直しで「仕事の始まり（枠: の頭）」を受けるようになった。93行の「見込みを書き替えた：その時の開始から数える」（`b.mkAt = st`）は、手番の始まりではなく仕事の始まりを受けるので、書き替えた刻で数えたいなら `b.mkAt = now` に替える案。
4. 表の見込みが段の足しで延びる件は計算が正しく、元の台帳（済んだ段が畳まれない・別の枠を同じ仕事に足す）が訳。窓の側の決め（作法45）の話。
