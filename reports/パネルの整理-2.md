```js
function stateLineText() {
  if (lastStat === '作業中') { return endPredText(); }
  if (lastStat === '手待ち' || lastStat === 'ヨシ待ち') {
    if (!sinceBase || !sinceBase.at) { return ''; }
    var min = Math.max(0, Math.floor((Date.now() / 1000 - sinceBase.at) / 60));
    return lastStat + '・経過' + min + '分';
  }
  return '';
}
```

| 状態 | 出る字 |
|---|---|
| **作業中** | **`作業中、HH時MM分終了予定`**（v90 のまま。`endPredText()` が組む） |
| **手待ち** | **`手待ち・経過N分`** |
| **ヨシ待ち** | **`ヨシ待ち・経過N分`** |

**行の位置も見た目も変えていない**（跡地の `li.why` に `p.m` の一行）。

### 決めごと

- **経過の基準は上の札と同じ `sinceBase.at`**（＝`state.json` の `statAt`）。
  二つの経過が食い違わないよう、同じ値から数える
- **上の札は「12分34秒」と秒まで出すが、こちらは分だけ。**
  跡地の行は毎秒は描き直さない（15秒ごとの取得で組み直す）ので、秒を出すと止まって見える
- **基準が取れないときは行ごと出さない。**「連絡なし」「読めない」のときに 0分 と言わないため
