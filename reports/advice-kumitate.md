# 助言の組み立て方（koushu-handan.html v1544）

行番号はすべて `koushu-handan.html`。コードを読んで書いたもので、今回は実行しての出現率の測定はしていない。
`advice-tone-core.js` は助言の字の部分の正本の写し（本体の ADV_TONE_BEGIN 2097 〜 ADV_TONE_END 3508）。

## 1. 流れ

1. **判定**：判定の釦で人格・方言のランダムが点いていれば抽選（10822 付近。人格7・方言8から。ランダムの方言に「方言なし」は入らない）→ `analyze()` → `attack = a.verdict==='attack'`（10991）→ `adviceFor`（4101、呼び出し 11006）。`a.tooMany` なら助言なし。
2. **場面の文**：攻めだけ `sceneAdvice`（2072）。条件は `sceneVoiceName`（2054）で、国士・役満手前・猫牌ありを除き、上から ①染め（他の色に完成面子がなく、最多の色が6〜13枚） ②役牌の対子 ③向聴0〜2で役もドラもない。①に入って外れた手は②③へ進まない。当たれば本文は場面の文と、巡目の一文（`advRetreatPart` 3598、向聴2以上。無ければ「何巡目まで、とは決めない」）。
3. **型どおりの本文**：場面に当たらない手と守り。`advSpeaker`（3547）が「見方の審判」を決め（判定と同じ側の人格のうち `REVOTE_W` 最大、いなければ ずんだ）、`advLines`（3619）＝`advLines0`（3620）＋受け直し `advEchoLs`（3475）。見方の審判は訳の中身を決める。喋る人格ではない。
4. **同時に用意する材料**（4101 内の `ctx`）：面白みの場面 `advOmoScene`（3829）、麻雀の言葉の候補 `advWordCands`（4070）、大物手の印 `big`（ドラ3以上）。
5. **一本にする**：`advCompose`（3754）→ 中の `mkLines`（3758）→ `advTalk`（3155）。喋る人格は `advTone`（3750、未選択は ずんだ。保存が無い時の初期値は執事 6062）、語り口は `advMode`（3751、ノーマル・デレ・ツン）、方言は `advDial`（3752）。

### 本文の選び順（advLines0）

**攻め**は、上から最初に当たった一つ。
国士 → 役満手前 → 七対子 → 対々和 → タンヤオ → 向聴0〜1 → 猫牌4枚以上 → 通常。

- 通常：訳 `adva-w-<審判>`（先生は、染めを本線にしない手か `adva-fl-1` の時は省く）→ 切る牌（`pickCutTile` 6690。染めを本線にしない時は `advFloatCut` 2038）と巡目 → ひと言を一つまで（二組以上の対子＋刻子、安全牌なし、ドラ浮き、字牌の対子などの順。何も足さない場合もある）→ 役満の一文・染めなどの測りの一文（`advMeas` 3605）・暗槓の一文は、条件が合えば足す。

**守り**は次の順に積む。
訳（九種九牌、でなければ 打点が安い → 遠い → 形が悪い → 安全牌が多い → 少ない → 対子が多い → 既定は形）→ 切る牌と残す牌 → 対子の種 → ひと言一つまで → 撤退の線 `advd-sen` → 九種九牌・ドラ4枚・暗槓の一文 → リーチを受けた時（二行）。九種九牌では出ない行がある。

### 並びの順（mkLines と advTalk）

1. 大物手の一言（`advBigLine` 3144。字がある時だけ）と判定の一言を、頭の同じ行に置く。判定の一言の候補は `advHeadCands`（3875）。`TONE_WORDS`（5302）か `DIALECT_WORDS`（5312）から、鳥 → 龍 → 際どい → 通常の順で集め、ツン・デレ版があれば使う。順はくじで、長さに収まる最初の一言を採る。
2. 本文。面白みの一言は、場面に応じて本文の前、切る牌の名の直後（あだ名）、最後のどこかに入る。
3. 麻雀の言葉（一行）。
4. 終わりの一言 `advc-…`（デレ・ツンだけ。三つから1つで、直前の物は除く `advPickOne` 3740）。面白みの一言が最後に来る時は付けない。
5. `advTalk` が行の前につなぎを入れる（`advConn` 2439。方言なしは `ADV_CONN_TONE` 2427、方言は `ADV_CONN_DIAL` 2433）。方言の時は、条件が合えば最初のつなぎが人物の口癖に替わる（`ADV_CHARA` 2179、`advKuseOk` 2384、`advKHere` 3154）。励ましの口癖は攻めの締めに回り、呼びかけは最後の対象の文に一度付く。全部の `items` を続けた字が、画面の一続きの助言になる。

## 2. 人格と方言の掛け方

1. **人格の字**：部品 id ごとに `advParts`（3709）→ `advToneText`（2156）。六人（執事・軍師・お嬢様・マダム・一姫・先生）は `ADV_TONE`（2100、`advRow` 2102）。ずんだと、表に無い部品は `ADV_TEXT`（2096）。場面の文は `ADV_SCENE`（2161）。
2. **方言の語尾**：`advDialAll`（2391）が文ごとに `advDialSentenceV`（2345）を掛ける。語尾は三通りで、`ADV_DIALECT`（2259）と `ADV_DIAL_VAR`（2327）を使う。番号は `advDialPlanAll`（2419）が 0,1,0,2 の順で割り振る。直前の文と同じ語尾になる時は別の番号を試す。コメントには「二、三文に一回」とあるが、今のコードは対象の部品すべてに番号を割り振る。
3. **上書き**：人格×方言の決め `ADV_PERSONA_DIAL`（3010。執事の分は `ADV_BUTLER_DIAL` 2958）の `fx`、種類ごとの `kfx`（仕組みだけで、今のデータに中身は無い）、書いた字の表 `ADV_KIND_LIT`（3080。部品 id か種類 `advKind` 2987 で引く）。
   - `std` が真の組（執事の宮崎・博多・京都・青森・沖縄と、幼児の七人）は、本文とつなぎを方言の語尾の層に通さない。幼児以外は `fx` も掛けない。幼児は `fx` を掛け、前後を「ばぶ」で挟む。
4. **語尾の重なり直し**（`advTalk` 内）：隣り合う二文が同じ方言の語尾なら、片方の方言を外すか、つなぐ・体言止め・問いかけにする。同じ末尾が三文続く時は、直せる文に `advAltLast`（2409）を掛ける。
5. 面白みの一言と大物の一言は書いた字のまま（`lit`）で、方言の変換を通さない。

## 3. 百語（麻雀の言葉）

「各人の百語」は麻雀の言葉の一覧を指すものとして書く。**実数は98語**。一覧は `ADV_WORDS`（3334）、出る条件は `ADV_WORD_ENGINE`（3921〜）。条件は103本書かれ、`DROP`（4067：w025・w027・w052・w092・w093）の5本を外して98本。種類は用語70・本物12・眉つば12・あだ名4。段は0が1語、1が29語、2が48語、3が20語。

### 出る条件

1. `adviceFor` が助言を作る手であること（場面の文の手も含む。攻め・守りの両方）。
2. `advWordCands`（4070）が、条件に当たった語のうち**一番高い段の語だけ**を残す。段0の w001 は条件が常に真なので、他に当たりが無ければ w001 になる。
3. そのあと、染めを本線にしない手（`flushBlocked` 2053）では w025・w026・w027・w029・w094 を除く。下の段へは戻らないので、候補が空になれば言葉は出ない。
4. `advWordPick`（4079）が候補から等確率で一つ引く。直近4語は避ける（全部が直近なら、直前の1語だけを避け、それも無理なら全候補）。記憶は端末の `koushu_adv_word` で、人格・方言に共通。同じ判定の中では、人格×方言ごとに引いた語を固定する。ここに「何回に一回」の確率は無い。
5. **長さの詰め**：`advVariants`（3485）と `advBad`（3458）。見積もり `advEst`（3456）が30秒以内で、26字以上の文が三つ続かず、同じ文末（末尾4字）が三文続かなければ採る。
   - 詰める順は、面白みの一言を外す → **麻雀の言葉を外す** → 短い言い方 → つなぎ外しなど → 最後の段（上限33秒）。
   - 言葉を外した後の段で、言葉が戻ることはない。
   - 判定の一言は、どれかの段で収まる最初の候補で決まる。言葉が残る別の候補を探し直すことはしない。
   - どの候補も収まらない時は、見積もりが一番短い結果を使う。

### 出る割合

- **今の版（v1544）で実際に画面に出る割合は、コードからは決まらない。** 候補は 3 で空になる場合を除いて必ずある。残るかどうかは、手・人格・方言・語り口・引いた語と一言で変わる全体の長さと語尾しだい。
- 語ごとの割合も同じく決まらない。配牌で各条件が当たる頻度、段の競り合い、直近4語の記憶に左右される。
- 参考の過去の実測：`reports/y1117-1500.md`（v1506 の時点）に、「30秒を越える場面では外れるので、出る割合は言葉の組の31％（残り69％は長さの都合で外れる）」とある。これは全組み合わせの測定で、実際の配牌の頻度で重みを付けた値ではない。その後の版でも文が変わっているので、今の値としては使えない。

### 参考：面白みの一言の割合（百語とは別の表）

`advOmoPick`（3849）。`ADV_OMO`（2445）は56組（方言8×人格7）で、**方言なしの組は無い**。場面が当たり、本文と意味が重ならない（`advOmoOverlaps` 2904 付近）時に回数を数え、4回に1回は足さない（選ぶ段階で3/4）。文は五つから、同じ場面で前に出した物を除いて引く。長さの詰めでは百語より先に外れるので、画面に出る割合は3/4以下になるが、値はコードからは決まらない。

## 4. 標準と方言は同じ表か

## 5. 声（字との対応だけ）

字と同じ並びから、`advCompose` が声の名の列を作る。字が変わらない部品は元の声（`advTokNames` 3721）。変わった部品とつなぎは、字から作る名 `advy-<8桁>`（`advDialVoice` 3259）。判定のあとに人格・方言の釦を押すと、`advRefresh`（3820）が字だけを組み直す。
