## 1. 計算式

**残り％ ÷ 次のリセットまでの残り日数（端数を含む）＝ 1日あたり使ってよい％。**

```powershell
$days = ($rAt - [datetimeoffset]::Now).TotalDays     # 端数つきの日数（時間を24で割った値）
$a = [math]::Round((100 - $wAll) / $days, 1)         # 週全体

```

**週全体と週Fable の両方**を出す。小数第一位まで。

### 「20:00 の回」について — いまの予定表は 21:00

`ClaudeDailyNotice` の起点を実読みした。

```
2026-08-27 09:00
2026-08-27 21:00
```

**20:00 の回は無い。** 夕方の回は **21:00**。そこで判じ方を **「18時以降の回」** にしてある。
いまの予定表ならこれで 21:00 の回にだけ付き、朝の回には付かない。

**20:00 へ動かすなら予定表の起点を変える要がある**（一行で済む）。
勝手に動かすと朝の回の刻も巻き添えになりかねないので、**指示を待つ**。

＊ちなみに**週のリセットは 20:00（現地）**（下記）。20:00 に出すと、
　**リセットの直前**の値を見ることになる。21:00 のままだと、リセット日の回は
　**リセット直後の値**（残り100%近く）になる。どちらが読みたいかで決まる。

## 3. 出どころ ── パネルが読んでいる値そのまま

`usage.json` の **`body.limits`**。パネル（`panel.html` L1732 の `USAGE_URL`）が読むのと同じ一枚。

| 何 | どこから |
|---|---|
| 週全体の現在% | `kind = weekly_all` の **`percent`** |
| リセットの刻 | 同じ行の **`resets_at`**（UTC） |
| 週Fable の現在% | `kind = weekly_scoped` かつ `scope.model.display_name = Fable` の **`percent`** |

**取れないときは行を出さない**（誤った数字を出さないため）。出さない場合は四つ。

- `usage.json` が読めない／`limits` が取れない
- 週全体が欠けている
- 週Fable が欠けている
- `resets_at` が読めない、または**既に過ぎている**（残り日数が0以下）
