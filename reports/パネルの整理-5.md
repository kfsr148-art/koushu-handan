```js

  if (lastStat === '作業中')   { return endPredText(); }

```

| 状態 | v93 まで | **v94** |
|---|---|---|
| 作業中 | `作業中、HH時MM分終了予定` | **そのまま** |
| 手待ち | `手待ち・経過N分` | **`次の指示待ち`** |

**数字はやめた。** この行が言うべきは「いま誰の番か」であって、待った長さではない。
数字が要るときは、上の札のヨシ待ちの側（`ヨシ待ち・N分N秒`）が持っている。

下の実測で、書き換えが一度回ったあとも字が変わらないことを確かめた。
