## 1. 実装（`usage-widget.js`）

### 式（`borderPct()`・L77-97）

**直近リセット刻からの経過24時間の数 × 100 ÷ 7。**
直近リセット刻は `resets_at`（次のリセット）から**週期7日を引いて**導く。

```js
function borderPct(iso) {
  let next = Date.parse(iso);
  next = Math.round(next / 60000) * 60000;       /* 分へ丸める（下記） */
  const last = next - 7 * 86400000;              /* 直近リセット刻 ＝ 次 − 7日 */
  const days = Math.floor((Date.now() - last) / 86400000);   /* 経過24時間の数 */
  return Math.round(Math.min(7, days) * 1000 / 7) / 10;
}
```

### 表示（L182-189）

**「20:00まで N%」** を、週全体と週 Fable の**両方**の行へ、「戻るまで」の左に添えた。

```
週全体     81%   20:00まで 71.4%  21時間後
週 Fable   58%   20:00まで 71.4%  21時間後
```

値が出ない回（`resets_at` が読めない）は添えず、今までどおりの形に落ちる。

### 実装の途中で見つけて塞いだ穴 ── 分への丸め

実物の `resets_at` には**小数秒**が乗っており（`…T11:00:00.469877Z`）、
さらに**二つの物差しで約1秒ずれている**。

```
weekly_all    : 2026-08-31T11:00:00.697168+00:00
weekly_scoped : 2026-08-31T10:59:59.697366+00:00
```

そのまま使うと、**20:00 ちょうどの境目で「まだ6日目が満ちていない」と読まれて1日ずれ**
（最初の実測で今日20:00 が 71.4% と出た）、**二つの行の値も食い違う**。
**分へ丸める**ことで、どちらも同じ 20:00 になり、両方の穴が同時に塞がる。
