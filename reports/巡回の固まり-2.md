## ② その段が何を待っているか（字面で追った）

`Take-Usage` の中で外を待つのは四つ。**三つには上限があり、一つには無かった。**

| 待つ相手 | 上限 |
|---|---|
| `curl.exe` … api.anthropic.com の使用量 | **25秒**（`--max-time 25`） |
| `git add` / `commit` / `push` / `pull` / `push`（usage.json） | **15／20／20／30／20秒**（`Git-Run` の `WaitForExit`） |
| **`claude --version`** | **無し** ← ここだけ返るまで待ち続ける |

**上限つきの分を最悪まで足しても 25＋105 ＝ 130秒**で、実測の 157.5秒とほぼ釣り合う。
**5分〜11分の固まりは、上限つきの分だけでは作れない。** 上限の無い一つが残りを説明する。

＊`claude --version` は Node の CLI を丸ごと起こす。10分ごとに一回、毎回起こしていた。
＊断っておくと、**「この呼び出しが原因だ」と現場を押さえたわけではない**（消えた回は記録が残らない）。
　言えるのは「**この段で上限が無いのはここだけで、固まりの長さは上限つきの分では説明できない**」まで。

## ③ 直し — 一日一度だけ調べ、それでも8秒で切る

```
控え（claude-ver.txt）に「日付<TAB>版」を持つ
  今日の控えがあれば … **起こさない**（10分ごとのプロセス起こしが消える）
  無ければ          … 起こすが **8秒で切る**（切ったら unknown のまま進む）
```

版は User-Agent に添えるだけなので、**取れなくても困らない**。切った回は記録に残す。
