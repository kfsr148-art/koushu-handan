## 2. ずれの正体 ── 知らせが「自分の札」を数えていなかった

乙で印が**写せますの札まで**進むようになったので、次の回に数えるのは**仕事の札だけ**になる。
ところが**貼る文には、その回の写せますの札も入る**。

```
仕事の札      1枚  ← 知らせが数えた分（M=1）
写せますの札  1枚  ← 数えていない
─────────────
貼ると入る    2枚  ← パネルの未写し（N=2）・釦は「残2／2件」
```

**釦と貼る文は 2 で合っていたが、知らせだけが 1 だった。**
釦が「残2／2件」と出ていたのは、`if (m < n) { m = n; }` の備え（v96）が
**M を N まで引き上げて隠していた**ため。ずれは残っていた。

## 3. 直し ── 知らせの数に自分の一枚を足す

裁定の「**N の意味は『貼ると入る件数』であり、写せますの札も貼る文に入る**」に合わせた。

`~/.claude/watch-notify.ps1` **L1779-1795**。

```powershell
# ---- 自分の札も数に入れる（2026-08-30・裁定の確定を受けて）----
#   ＊N の意味は「**貼ると入る件数**」。写せますの札そのものも貼る文に入るので、
#     ここで数えた分に**自分の一枚を足す**。
#   ＊自分の札はまだ控えに無い（Flush-Quick が台本の終わりで入れる）ので、
#     数えるのではなく**足す**。必ず一枚なので、足し算で過不足は出ない。
$nShow = $n + 1
[void](Send-Ntfy $T_DONE ('写せます（' + $nShow + '件）') '4' 'copy' 'ready')
```

**足し算を四通りで確かめた。**

| 仕事の札 | 知らせ |
|---|---|
| 0件 | **（出さない）**（今までどおり） |
| 1件 | **`写せます（2件）`** |
| 2件 | `写せます（3件）` |
| 5件 | `写せます（6件）` |

**これで三点が同じ数を指す** ── 知らせ **2** ／ 釦「残2／**2**件」 ／ 貼る文 **2件**。
