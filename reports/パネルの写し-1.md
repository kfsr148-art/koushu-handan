**L780-790**（`buildBundle()`）── `out` を組んだ直後に `unshift` で一行だけ足す。

```js

if (working.length) {
  out.unshift('未了 ' + working.length + '件：'
    + working.map(function (d) { return String((d && d.title) || '(題なし)'); }).join('、'));
```

## 一つ申し送り

**1と2は、そのままでは同時に効かない。** 1で作業中のあいだ釦を押せなくするので、
2の「未了 N件」の行が**その釦の写しに出ることは無い**（押せないから写しが作られない）。

そのまま両方入れてある。2の行が働くのは、**字を組んだ後に状態が変わった回**と、
**釦以外の道で写しを組んだ回**の備え。写しだけを見て「まだ途中がある」と分かる形は残る。
どちらか一方だけにするなら言ってほしい。
