## では 08:55 の起こし直しは何だったか

記録はこう並んでいる。**読み違いではなく、本当に閉じられていた。**

```
2026-09-21 08:48:15  鍵 … done  （プロセス2本・窓2・迷子0）
2026-09-21 08:52:34  画面が見えなくなった 2 -> 0（プロセス 2 -> 2）   ← 窓が閉じられた。プロセスはまだ残っている
2026-09-21 08:53:27  dead    対話の claude が0本                  ← 1分後にプロセスも終わった
2026-09-21 08:55:27  revive  起こし直した（今日1回目・0本が2分続いた・落ちを見た刻 08:53:27）
2026-09-21 08:59:18  鍵 … done  （プロセス1本・窓1・迷子0）
```

**08:52:34 の一行が決め手**——`画面 2→0` と同じ行に `プロセス 2→2` が出ている。
畳んだだけなら画面は 2 のまま。**閉じたから画面だけが先に 0 になり、1分遅れてプロセスが 0 になった。**

## もし直すなら（**していない**）

「**画面が見えなくなった**」の札は、**プロセスが減っていない回にも出る**。
閉じた直後の1分間は必ずこの形になるので、**閉じるたびに一枚出る**。
消したいなら「**プロセスも同時に減った回だけ出す**」にできる。
**代償**＝窓だけが消えてプロセスが残る本当の異変（隠された窓・描画の失敗）を、**そのぶん見落とす**。
いまの形は「**窓が消えたら必ず言う**」側に倒してあり、これはこれで筋が通っている。
