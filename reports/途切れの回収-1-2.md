## 塞いだ穴

**`dead`（窓が落ちた）と `stale:`（生存の記録が途切れた）は、
札は立つのに押し送りが出ていませんでした。**

原因は状態を決める一行（旧 L1489）。

```powershell
$state = $(if ($key -like 'wait:*') { 'wait' } elseif ($key -like 'done:*') { 'done' } else { '' })
```

`dead` も `stale:` も `else` に落ちて**空の名乗り**になり、`Push-Ntfy` が断っていた。
**窓が落ちても、見張りが途切れても、iPhone は鳴らない**——いちばん気づけない形でした。

```powershell
$badKind = ''
if ($key -eq 'dead') { $badKind = 'dead' } elseif ($key -like 'stale:*') { $badKind = 'stale' }
…
if ($badKind) {
  if ($badPrev -eq $badKind) { Write-Self ('押し送りはしない（' + $badKind + ' は既に一発送った。戻るまで出さない）') }
  else { $state = 'bad'; Set-Content -LiteralPath $BadPushPath -Value $badKind …; Write-Self ('異常の押し送りを一発出す（' + $badKind + '）') }
} elseif ($badPrev) {
  Remove-Item -LiteralPath $BadPushPath -Force
  Write-Self ('異変から戻ったので、異常の押し送りの印を落とした（前は ' + $badPrev + '）')
}
```

**決めごと三つ。**

- **印は「種類」で持つ**（`dead` / `stale`）。`stale:` は後ろに刻が付いて毎回変わるので、
  **鍵そのものを控えると毎回「新しい異変」に見えて鳴り続ける**
- **公開側を待たずに出す。** 窓が落ちている・見張りが途切れているときは、
  **控えが公開へ届く見込みそのものが薄い**。待つと知らせが埋もれる
- 題は**猫の言い回しにしない**。手が要る合図だけは、ふだんの三種（😼😽🙀）と見分けが付いてほしいため

## 実測 ── 本物の判定の段を、そのまま抜き出して回した

`watch-notify.ps1` の **L1590〜L1621（32行）を字面のまま抜き出し**、
印の置き場だけ一時の場へ差し替えて作り値の鍵を通した。
**本物の `bad-pushed.txt` には触っていません。**

### `dead`

```
1回目（窓が落ちた）        鍵=dead   名乗り=bad    押し送り=**出る**  題「🪟 異常です（手が要ります）」
2回目（同じ状態が続く）     鍵=dead   名乗り=（空）  押し送り=出ない
3回目（同じ状態が続く）     鍵=dead   名乗り=（空）  押し送り=出ない
戻った（作業中）           鍵=run:…  名乗り=（空）  押し送り=出ない   ← 印を落とした
戻ったあとの1回目（再発）    鍵=dead   名乗り=bad    押し送り=**出る**
```

### `stale:`

```
1回目（生存が途切れた）     鍵=stale:17:01:00  名乗り=bad    押し送り=**出る**
2回目（刻だけ違う）        鍵=stale:17:02:00  名乗り=（空）  押し送り=出ない
3回目（刻だけ違う）        鍵=stale:17:03:00  名乗り=（空）  押し送り=出ない
戻った（手待ち）           鍵=idle:17:04:00   名乗り=（空）  押し送り=出ない   ← 印を落とした
戻ったあとの1回目（再発）    鍵=stale:17:05:00  名乗り=bad    押し送り=**出る**
```

**刻だけ違う `stale:` で二度目が出ない**ことが要点。種類で印を持った狙いどおり。

### 混ざったとき（`dead` → `stale:` は別の異変）

```
dead の1回目               名乗り=bad    押し送り=**出る**
続けて stale:（種類が違う）    名乗り=bad    押し送り=**出る**
その stale: の2回目          名乗り=（空）  押し送り=出ない
```

**別の種類なら、続けて起きても一発ずつ出る。**

### まとめ

| 場面 | 出るか |
|---|---|
| `dead` 1回目 | **出る（1発）** |
| `dead` 2回目・3回目 | 出ない |
| `stale:` 1回目 | **出る（1発）** |
| `stale:` 2回目・3回目（刻だけ違う） | 出ない |
| 戻ったあとの再発 | **また出る（1発）** |
| `dead` のあとの `stale:`（別の種類） | **出る（1発）** |

**十一通りとも、指示どおりの振る舞い。**
