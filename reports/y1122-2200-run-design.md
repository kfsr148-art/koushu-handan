## 二、案：枠一つ＝一走り（走り手＋課題＋確かめ役）
```
課題（Issue）の「開」から一つ取る ─→ 走り手（run-one）が claude -p を一走り
   └ cwd＝作業の置き場／--allowedTools＝枠ごと／--max-budget-usd／外からの timeout／--setting-sources project（user の hooks を読まない）
走りの json（result・session_id・cost・is_error・terminal_reason）
   └ 札は json から機械が作る（題は確かめの後で決める）
確かめ役（別の読むだけの一手）が、枠の「済みの条件」を実行して ○×
   ○ → 課題に結果の札を書き、閉じる／× → 訳を付けて課題へ差し戻し（走りを一度やり直す）
問い（本人に訊く事）→ 課題の別のコメント＋ラベル「ヨシ待ち」＋🙋の札（印は課題番号）
次の「開」へ
```
- **前の流れの渡し方**：同じ session_id を `--resume` すれば前の文脈が続く（試しで確かめた：1回目の合言葉を2回目が答えた）。**ただし枠は別々に走らせ、渡しは「課題の本文と結果」に書く**（窓のように前の枠の記憶を持ち越さない）。続けたい時だけ resume。
- **時間の上限**：旗は無い。**外から timeout で切る**＋`--max-budget-usd`。切れたら課題に「上限で切った」を書いて差し戻し。
- **使用量切れ**：走りが `is_error` で返る見込み（今の見張りの「使用量の止まり」の判定 `reboot-hold.js --usage-only` を、走り手が走る前に見る）。**実際の出方は未確認**。

## 六、百五十：枠一つ＝課題（Issue）一つ
- **対応**：開＝未了・閉＝済。本文＝枠（頭の一行・本文・済みの条件）。コメント＝受領・結果の札・問い・ヨシ。ラベル＝ヨシ待ち（印＝課題番号）・雲待ち・本人の決め待ち。日付の刻は GitHub が付ける（機械の刻の取り違えが消える）。
- **置き場**：`koushu-state` は公開（読み元が raw／Pages）。**課題の本文には秘密（鍵・内部の道）が混ざり得る**ので、**非公開のリポジトリ（例：koushu-ops）を別に切る**。公開側に出すのは panel 用の要約（今の state.json 相当）だけ。
- **パネル・押し送り**：走り手（と確かめ役）が課題の変化から state.json と札（ntfy・panel の札）を作る。課題の更新を知る道は **ポーリング（30〜60秒・`gh api`）**が素直（webhook は VAIO に受け口が無い）。
- **センコ（チャット側）**：課題を直に書ければ、橋の文書・合図の枝・ベルが要らなくなる。**センコの側から非公開の課題を書ける道（GitHub のコネクタ等）は未確認**。無ければ、今の橋の文書を「課題の写し」として残す（二重になる）。
- **利点**：台帳の「別の刻の行が閉じない」（百三十・百三十五）が型ごと消える／問いはコメント＋ラベルで札に埋もれない（百四十五）／履歴が課題に残る。
- **危うい所**：GitHub が落ちると全部止まる（今の台帳はローカルで動く）／API の枠と遅れ／課題の本文の公開の事故（非公開にする事で防ぐ）。

## 七、百五十一：済みを走り手が決めない（確かめ役）
- **枠ごとに「済みの条件」を一行付ける**（センコが書く。見て○×が分かる物）。例：「公開の ver.txt が 1517」／「panel に赤い行が無い（幅390pxで）」／「`reports/y1122-xxxx.md` が push 済み」／「雲の検査が success」。
- **走り手の「済み」は申し出扱い**。**確かめ役**（読むだけ・別の一手）が条件を実行し、**○の時だけ課題を閉じる**。×なら訳を付けて課題へ差し戻し（走りをやり直す・回数の上限を付ける）。
- **確かめ役を何で回すか**：①機械的な条件（curl・grep・git・node で○×が出る物）は**スクリプト**（試しの `cond-ok.js` の形）。②見て分かる程度の条件は**別の読むだけの `claude -p`**（`--allowedTools Read` のみ）に条件と成果物を渡して○×を言わせる。**書き込みを許さない**ので、確かめ役が成果物を直してしまわない。
- **条件が○×にできない枠**（言い回し・好み）は、**本人のヨシ（🙋）で閉じる**（課題のラベル「ヨシ待ち」）。
- 効く所：今日の「受領だけで台帳を替え忘れ（百三十）」「済んだのに順番待ちに残る（百三十五）」「本人の画面とセンコの数の食い違い」は、**済みを走り手（窓）が自分で言う所**から出ていた。
