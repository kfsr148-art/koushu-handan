**状態** … 終わり（2026-09-05 17:4x）

16:51 に立った終わりの札は、本文が
**「飽和の回避-1（重い帯で見張りと生存を落とす）／何をしたかの控えがありません（止まる側の書き忘れです）。」**
の二行だけだった。報告の中身が札に載っていなかったので、`reports/` 側から読んで立て直した。

## 控えが書かれなかった理由（一行）

**控えの見出しを「`完了:`」だけの空行にして、中身を次の行から字下げで書いたため。**
読み手は同じ行に一字以上あることを求めるので、見出しの行が欄を開かず、続きが全部落ちた。

字面 … `watch-notify.ps1` の `Get-Note`（本物の L264〜L365）

```
elseif ($t -match '^完了[:：]\s*(.+)$')   { $r.done  = $matches[1].Trim(); $cur = 'done' }
elseif ($t -match '^ファイル[:：]\s*(.+)$') { $r.files = $matches[1].Trim(); $cur = 'files' }
elseif ($t -match '^実測[:：]\s*(.+)$')   { $r.meas  = $matches[1].Trim(); $cur = 'meas' }
```

`(.+)` は**一字以上**を求める。`完了:` で行が終わると、この枝に入らない。
枝に入らなければ `$cur` が `'done'` にならず、**字下げした続きの行は足す先が無いまま捨てられる**。
`ファイル:` `実測:` も同じ形で書いていたので、**三つとも空**になった。

＊`待ち:` だけは `(.*)`（空でも通る）なので、この書き方でも落ちない。
　作法25 が「`待ち:` の行だけは省いてはならない」と決めている欄で、空を許すように作ってある。
　**空を許すのはこの一欄だけ**、というのが今回の分かれ目だった。

## 実測（写しに probe・本体には触っていない）

`Get-Note` を字面のまま抜き出し、四通りの控えを読ませた。

```
(甲) 完了: の行を空にして次行から字下げ  → 完了 **空**  ファイル **空**  実測 **空**
(乙) 完了: の同じ行から書き始める        → 完了 2行     ファイル 有      実測 有
(丙) 完了: の同じ行だけ・続き無し        → 完了 1行     ファイル 有      実測 有
(丁) 16:51 当時の実物（work-note.txt）   → **三つとも空**（札の「控えがありません」と一致）
```

**(丁) が札の見え方とぴたり合う。** 書き忘れではなく、**書いたが読まれなかった**。

直したあと、同じ probe に**いまの控え**を読ませた。

```
(丁) いまの実物（work-note.txt）  → 完了 16行  ファイル 有  実測 有
```

## 立て直しの途中で見つけた二つ（どちらも生存の間隔の話）

### 一．**生存はそもそも間引けない**（12分は成り立たない）

予定表 `ClaudeHookHeartbeat` の起こしは **PT10M（10分ごと）**。関門が求める間隔を
**10分より長くすると、10分の回が必ず見送られ、通るのは次の20分の回**になる。
20分は `$STALE_MIN`（15分）を超えるので、**重い帯のたびに嘘の 🪟 が鳴る**。

前回 20分→12分にしたのは、この算がまだ見えていなかった。**12分でも実際には20分になる。**

**要る間隔を 540秒（9分）にした。** 予定表の600秒より短いので、**10分ごとの回は帯の中でも毎回通る**。
つまり**生存は間引かない**。間引くのは**見張りだけ**（毎分→5分）。

**作り値（予定表と同じ10分間隔で呼ぶ）**

```
(甲) 帯なし・前の回から10分            → 生存が入った
(乙) 帯あり（いま）・前の回から10分     → 生存が入った
(丙) 帯あり（45分前・切れた）・10分     → 生存が入った
(丁) 帯あり・前の回から3分（参考）      → 見送られた（9分未満なので正しい）
```

### 二．**帯の中の途切れは「間隔」ではなく「2分で殺される」ことが原因**（報告のみ・直していない）

17:40:44〜17:52 の帯で、生存が **17:38:22 → 17:52:56（手で入れた）** と空いた。
**関門の見送りではない**（`heavy-skip.log` にこの時間の beat の見送りは無い）。
予定表の記録が答えを持っていた。

```
17:48:03  ID=200/100/129  起こした
17:50:03  ID=329          実行に割り当てられた時間を超えたため終了させた
最後の起こし=17:48:48  結果=267014
```

**`ExecutionTimeLimit` は PT2M。**重い検査で機械が詰まっている間は、生存の一行を書くだけの手も
2分を超え、**殺されて一回分が消える**。**間引いても、残った回が殺されるので効かない。**

塞ぐには次のどれかになるが、**どれも作りを変える案なので実装せず止める**（枠の但し書き）。

1. `ExecutionTimeLimit` を延ばす（PT2M → PT5M）。溜まった場合の振る舞いを併せて決める要がある
2. 生存の一行を**いちばん先に書いてから**残りをする（`hook-notice.ps1` の順に触る）
3. 重い検査のブラウザを一度に1本へ絞る（既に「止めた案」に挙げてあるもの）

＊今日の帯で実際に消えたのは **17:48 の一回**。9分にしたことで見送りは無くなるが、
　**この一回は間隔の話ではないので残る。**

### 一．の続き — **9分でも足りず、生存の間引きは外した（確定）**

9分（540秒）にしても穴が開いた。**予定表の刻からずれた所で生存が一度入ると、
次の回がその間隔に足りずに見送られ、そのまた次まで空く。**

```
18:12:08  手で生存を入れた（刻が予定表からずれる）
18:18     予定表の回 … 前の回から 5分52秒 ＜ 9分 なので **見送り**
18:28     次の回 … ここまで **16分** 空く（15分を超える）
```

**要る間隔をいくつにしても、この形は残る。**予定表は10分ごとの決まった刻で鳴るのに、
生存はそれ以外の刻にも入るため、**「前の回からN分」で測る限り必ず一回飛ばせる。**

**よって、生存の間引きは外した。**`$EVERY_SEC = 0`。**帯の中でも毎回そのまま走る。**
枠の②のうち「生存は10分→20分」は、**この仕掛けでは成り立たないので実装していない。**
**間引くのは見張りだけ**（毎分→5分）。

**作り値（最後の形）**

```
生存 … (甲) 帯なし・10分  → 入った   (乙) 帯あり・10分 → 入った
       (丙) 帯が切れた・10分 → 入った (丁) 帯あり・3分  → 入った
       (戊) 帯あり・30秒    → 入った          ＝ どの場合も毎回走る
見張り … 帯の中で続けて2回呼ぶ → 見送りの記録が2件増えた（間引きは効いたまま）
```

**枠に対して、できたこと・できなかったことを分けて書く。**

| 枠の指示 | 結果 |
|---|---|
| ①`heavy.txt`（30分で自動失効） | できた |
| ②見張り 毎分→5分 | できた |
| ②生存 10分→20分 | **できない。**15分の物差しに掛かるため、間引き自体を外した |
| ③pipe-check が同じ帯を見る | できた |
| ④作り値と実地 | できた（上の表と、15:45／16:34 の二回の帯） |
