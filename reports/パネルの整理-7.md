## 1. M の出どころを替えた

| 版 | M が指すもの | 出どころ |
|---|---|---|
| v95 | 控えの札の**全数** | `allRows.length` |
| **v96** | **直近の「写せます（N件）」の知らせと同じ数** | 控えの札の本文から読む |

**なぜ替えたか** ── v95 の M は「溜まっている総量」で、**いま片付いたひとまとまりの大きさ**ではなかった。
知らせが「写せます（2件）」と言っているのに釦が「全20件」と出ると、どちらを見ればよいのか分からない。

### 読み方（`panel.html` L841-857）

```js
/* 直近の「写せます（N件）」の知らせが言っている数を読む（v96）。
   ＊控えの札（allRows）を新しい順に見て、本文に「写せます（N件）」を含む
     いちばん新しい一枚から N を取る。
   ＊まとめ札（「この間にまとまった知らせ 2本」）の中に入っていることもあるので、
     一行目だけでなく**本文のどこでも**当てる。 */
function lastReadyCount() {
  var best = null;
  (allRows || []).forEach(function (d) {
    var mm = String(d.message || '').match(/写せます（(\d+)件）/);
    if (!mm) { return; }
    var t = d.time || 0;
    if (!best || t > best.t) { best = { t: t, n: parseInt(mm[1], 10) }; }
  });
  return best ? best.n : 0;
}
```

**知らせの本文に書いてある数をそのまま読む**ので、知らせ側（`watch-notify.ps1`）と
**必ず同じ値**になる。数え直しはしない。

### 釦の字（`panel.html` L868-882）

```js
var n = buildBundle().count;
var m = lastReadyCount();
if (m < n) { m = n; }
if (n > 0) { b.textContent = 'まとめて写す（残' + n + '／' + m + '件）'; … }
```

**落とし方を二つ置いた。**

- **知らせが一度も出ていない**（控えに「写せます」の札が無い）… M が 0 になるので **N をそのまま使う**（`残N／N件`）。0 と出すより意味が通る
- **知らせのあとに札が増えた**（N が M を超える）… **N に揃える**。
  `M が N より小さい字`（残のほうが多い、という読めない形）は出さない

## 4. 実測（作法14「写しに probe」）

`panel.html` の写しを一時の場に作り、IIFE の内側へ一片を差し込んで headless の Edge を
`--dump-dom` で回した。**本体には何も入れていない**（写しごと消した）。

控えの札を新しい順に並べ、**新しい K 枚だけ未写し**にして釦の字を読んだ。
K を減らすのが「一部を写していった」姿にあたる。

```
直近の「写せます」の N : 2件 ／ 控えの札 20枚

未写し   釦の字                 押せるか   描かれるか   count
2枚     まとめて写す（残2／2件）   押せる    出ている     2
1枚     まとめて写す（残1／2件）   押せる    出ている     1
0枚     まとめて写す（0件）        押せない   畳んでいる   0
5枚     まとめて写す（残5／5件）   押せる    出ている     5
```

| 場面 | 釦の字 |
|---|---|
| **知らせの直後**（まだ一枚も写していない） | **`まとめて写す（残2／2件）`** |
| **一部写したあと**（2枚のうち1枚を写した） | **`まとめて写す（残1／2件）`** |
| 全部写した | 畳む（釦なし） |
| 知らせのあとに札が増えた（未写し5＞M2） | **`まとめて写す（残5／5件）`**（N に揃うガードが効いている） |

**M は 2 のまま動かず、N だけが 2 → 1 → 0 と減る。** 全部写せば N は 0 で釦は畳まれる。
