# 見張りの地図 — `watch-notify.ps1` の巡回を、段ごとに開く

**コードには触っていない。**読んで写しただけの一覧。

## 0. どう起こされるか

```
予定表 ClaudeWatchNotify（毎分・上限 PT10M・多重は IgnoreNew）
   └→ heavy-gate.ps1 -Run watch-notify.ps1 -EverySec 300 -Tag watch
        ├ 重い帯なら … まるごと見送る（帯の間に来た枠は控える）
        └ 帯の外なら … そのまま watch-notify.ps1 を同じ中で呼ぶ
```

＊`IgnoreNew` … 前の回が走っていれば、次の起こしは**予定表の側で捨てられる**（ID=322）。
　巡回が長引くと、その間の回は丸ごと無くなる。

## 2. 送る道（第5段の中身）

```
知らせを立てる
  ├ 急ぎ（終わり・写せます）      → Flush-Quick        … その回のうちに出す
  └ それ以外                      → 預かり（60秒）→ Flush-Held
                                     └ 10分で頭打ち（公開を待たずに出す）
出す手前で必ず二つ
  ├ Push-WhenVisible … 公開側に札が出たか（出ていなければ次の回へ預ける）
  └ Ntfy-OkToPush   … 話題名がある・落ちていない
最後に Push-Ntfy … 題の一行だけを ntfy へ（本文は載せない）
```

**立ちうる知らせ**（すべて**一つの作業につき一発**）

| 題 | いつ | 一発を担保する印 |
|---|---|---|
| 😸 走り出したにゃ／終了予定はHH時MM分 | 開始の時計が入った最初の回 | `start-pushed.txt`（形＋件名＋刻） |
| 🕒 終了予定を過ぎています | 見込みを超えた | `mikomi-over.txt` |
| 🙋 返事してください | 控えに待ちがある | 5分ごとに出し直す（待ちが続く間） |
| ✅ 終わりました（返事不要） | 鍵が `done:` | `done-said.txt` |
| 🔎 調べました | 控えの `種類: 調べた` | 同上 |
| 🐈 写せます（N件） | 中身のある未写の札が増えた | `copy-ready.txt` |
| 🪟 異常です（手が要ります） | 窓が落ちた・生存が15分途切れた・郵便受けの詰まり | `bad-pushed.txt`。**別の一枚**として立てる |

## 5. 触ると壊れる所（この地図の使いどころ）

- **位相の鍵（第3段）** … ここを触ると全部の知らせの出方が変わる。**判定の大元**
- **札の作り（`notify-record.ps1`）** … パネルの数・目次・写しが全部ここに乗っている
- **一発の印** … 消すと鳴り続け、増やすと黙る。**印の鍵に何を入れるか**が肝
- **`analyze()` ／ `bestShapeOneSuit`** … 本体の側。作法5 で変更禁止
