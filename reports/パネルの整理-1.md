## 1. 「あなた待ちは0件」の箱を消した

### 有るときにどう出しているか（確かめた）

`panel.html` **L607-635**。折り畳み式の箱で、**表紙＋写す釦**が一行、開くと中身が出る。

```
あなた待ち（1件）［写す］
  1. 試しの待ち（裁定待ち）
     印 y-test ／ 立てた 2026-08-30 11:00 ／ 裁定待ち ／ ヨシ（裁定）が返れば進む
```

**この形はそのまま残した。** 消したのは**0件のときの表紙だけの箱**。

```js
/* ---- 0件の箱は出さない（v90）----
   ＊v89 までは「あなた待ちは0件」という表紙だけの箱が常に居座っていた。
     **無いことを言うためだけの箱**で、読む場所が一つ増えるだけだった。
   ＊有るときの表示（表紙＋写す釦＋開いた中身）は**そのまま残す**。 */
if (w.length) {
  h += '<li class="why ack board' + (isOpen(wk) ? ' open' : '') + …
  …
  h += '</li>';
}
```

＊`waitText()`（**L680-684**・写す釦が使う写しの字）の0件の枝は残してある。
　釦そのものが0件のとき描かれないので通らないが、**古い画面を押したときの備え**として置く。

## 2. 跡地へ、作業中の終了予定の一行

`panel.html` **L637-644**。**字だけの行**で、押せる物ではない。

```js
/* 作業中のときだけ、終了予定を字だけの一行で出す（v90）。
   ＊置き所は「あなた待ちは0件」の箱が居た跡地。**釦とは別**で、押せる物ではない。
   ＊字は釦と同じ endPredText() から取る。二箇所で作らない。
   ＊作業中でなければ、この行ごと出さない。 */
if (lastStat === '作業中') {
  h += '<li class="why"><p class="m">' + esc(endPredText()) + '</p></li>';
}
```

**字の組み立ては一箇所へ寄せた** ── `endPredText()`（**L568-588**）。
v89 まではこの組み立てが `setCopyBoardLabel()` の中にしか無かった。
**同じ字を二箇所で作ると必ずずれる**ので、先に関数へ出してから両方が呼ぶ形にした
（釦の側は **L824-826** が呼ぶ）。中身（刻の当て方・過ぎたら延ばす）は v82 のまま。

**「まとめて写す（N件）」の釦は v89 のまま。** 未写しが有れば作業中でも押せる。
