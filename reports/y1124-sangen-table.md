# 小三元・大三元（三元牌）の相手あり測り（枠 二百五十六・11-24）

条件：子の一席に作り配牌（配牌の三元牌の形：p1＝対子1組／p2＝対子2組／t1＝刻子1／t1p1＝刻子1＋対子1／t2＝刻子2／t1p2＝刻子1＋対子2／t2p1＝刻子2＋対子1＝小三元の一歩手前）を積み、他三席は機械（majiang-ai）。腕＝push（三元牌を残してポンあり・ダマ）／pushR（門前で聴牌したら立直）／base（機械の普通打ち）。同じ山・同じ席。雲（1230秒×4本）・約171〜174組／枠。元：reports/cloud-sangen-aite-20261124-101504.tsv。役牌（三元牌のポンだけの翻牌）は枠 258 で取りやめたので、形の和了は小三元か大三元が付いた和了だけを数える。

## 要点（窓の読み）
- **どの枠でも、三元牌を残して小三元・大三元へ寄せると、点は普通に打つより低い**：push−base の点棒の差は −300〜−2,900点（p2 −1,575±883・t1 −1,346±744・t1p1 −1,918±892・t2 −2,815±1,149 は誤差の外、p1 −296・t1p2 −2,737±2,749・t2p1 −2,929±3,273 は誤差の内だが同じ向き）。
- 形（小三元・大三元）の和了は、普通に打っても出る：t1p2 は push 35.7%・base 47.4%、t2p1 は push 38.6%・base 46.8%（機械の普通打ちの方が高い）。大三元（役満）も t2p1 で push 32.7%・base 35.7%。
- 刻子や対子を残して押す分、和了率は 2〜12pt 下がり、放銃は −5〜+14pt。
- **助言の向き：値打ちが無い（寄せて点が増える枠は無い）→ 「普通に打て」型の一文だけ**（枠 256 の三）。
