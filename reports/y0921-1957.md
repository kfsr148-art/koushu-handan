## 1. 入れた形

**`usage-good.json` の数で判じる。**「Retrying」は窓へ出す字で誰も拾っていないので、数えられる物で見る。

| | |
|---|---|
| 見るもの | `body.limits` の三つ … **`weekly_all`＝週全体** ／ **`weekly_scoped`（Fable）＝週Fable** ／ **`session`＝セッション** |
| 手待ちにする条件 | **どれか一つでも `percent` が 100 に達していたら**、受信箱から枠を**取らない** |
| 鳴らす物 | **「🪟 使用量の上限で手待ち（戻り HH:MM）」を一度だけ**（控えは `usage-hold.txt`／鍵は `種類\|戻りの刻`） |
| 取り直す | **`resets_at` を過ぎたら取る。** 数が 100% のままでも取る——刻を過ぎたら、こちらが止め続ける理由が無い |
| 上限を割ったら | 控えを落として、また取りに行く（次に上限へ達したら改めて一度鳴る） |
| 読めない回 | **取る側へ倒す**。黙って止まるのがいちばん悪いので |

## 5. 甲を採らなかった理由（記録として）

甲＝窓を `… claude.exe … > window-out.log 2>&1` で起こして `Retrying` を数える案は、
**`ClaudeCodeAtLogon` の起こし方に触る**（窓の題・`/MAX`・コンソールの字が効かなくなる恐れ）。
乙は**既に在る数**だけで済み、窓の起こし方に一切触らない。
＊ただし乙は「Retrying 三連」そのものではない。**上限に達する前の弾かれ（一時的な429）は拾えない。**
　そこまで要るなら、そのとき甲を足す。
