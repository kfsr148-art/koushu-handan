**N＝0 は誤りではなく、「未写しの札が0枚」という正しい値だった。**
食い違っていたのは**「写せる札」の定義**——

- v84 の N … **未写しの札**（`shown.filter(!isDone)`）。全部写したので 0

**写しの独立-1 の① は「終わりましたに立った札とヨシした数の札も写せる形にする」**だった。
v84 はそこを満たしていなかった。

## 2. 直し（v85・`panel.html` L920-931 と L933-937）

**未写しが0件のときは、「終わりました」の箱を読み返しで写す。**

```js
var todo = (shown || []).filter(function (d) { return !isDone(d); });
var reread = false;
if (!todo.length) {
  var back = (allRows || []).filter(function (d) { return isDoneNotice(d && d.title); });
  if (back.length) { todo = back; reread = true; }
}
```

読み返しの回は、頭に断り書きを一行立てる。

```js
if (reread) {
  out.splice((lastStat === '作業中') ? 2 : 1, 0,
    '読み返し ' + todo.length + '件：未写しは0件なので、終わりましたの箱をそのまま写します');
}
```

**決めごと。**

- **順は「未写しが先、読み返しが後」。** 未写しが1枚でもあれば、そちらだけを写す
  （読み返しを混ぜると、写したばかりの札がまた出てくる）
- **N は変わらず「押せば写る札の数」。** 読み返しの回は読み返す枚数がそのまま N になる
- 畳むのは、**未写しも終わりましたの箱も両方0件**のときだけ
- 作業中で両方0件なら「作業中、HH時MM分終了予定」（v84 のまま）

## 3. 三件の報告の札がどこへ行ったか

`notices.json`（20件）を全文で当てた結果。

| 探した字 | 見つかった数 | どこ |
|---|---|---|
| **穴の直し** | **1件**（09:00） | **定時の報せの本文**に出ているだけ。報告の札ではない |
| **写しの網** | **0件** | **どこにも無い** |
| **札の題** | 1件（前日 23:19） | 別件の報告の中の字 |
| 写しの独立 | 2件（09:00 の定時の報せ／**05:45 の報告の札**） | 05:45 のは本物の報告の札 |

**消えた経路は二つあり、別々のもの。**

### （イ）穴の直し-1① … 作られたが、後から消された

**写しの網-1 で報告したとおり。** 04:28 に控えへ入ったが、05:06 のまとめ札が
**本文の一行目が同じ**（`この間にまとまった知らせ 2本`）だったため置き換えで消えた。
**直しは 05:35 に入れたので、04:28 の札には間に合っていない。**

### （ロ）写しの網-1・札の題-1 … **そもそも作られていない**

見張りの記録に、その時刻の知らせが**一本も無い**。

```
2026-08-30 05:06:39  控えへ入れた [✅ 終わりました（返事不要）]      ← 通知の題-5
2026-08-30 05:45:11  急ぎの知らせに積んだ [✅ 終わりました…]         ← 写しの独立-2
                     ↑ この間（05:07〜05:44）に知らせが一本も無い
```

**理由** ── 知らせは「Claude Code が止まった（`run:` → `done:`）」ときに立つ。
写しの網-1・札の題-1 を仕上げた 05:38〜05:40 は、**次の枠（写しの独立-2）が
応答の途中で届いたため止まっておらず、`run:` のまま続いていた。**
止まったのは 05:44:51 で、そのとき立った札が「写しの独立-2」だった。

**消えたのではなく、作られていない。** 中身は失われておらず、
`reports/写しの網-1.md` と `reports/札の題-1.md` に在る。

＊raw … `https://raw.githubusercontent.com/kfsr148-art/koushu-handan/main/reports/写しの網-1.md`
＊これは連携の穴-1 ⑤（イ）「応答の途中で届いた枠は `UserPromptSubmit` が鳴らない」と
　**同じ根**から出ている。枠が途切れずに続くあいだ、機械から見ると仕事は一つのまま。
