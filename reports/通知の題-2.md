## 1. 直した所

`~/.claude/daily-notice.ps1` **L116** の一行を、**見張り四つの結果から選ぶ形**へ替えた（L116-127）。

```powershell
$allOk = ($alive.Count -gt 0)
foreach ($a in $alive) { if ($a -notmatch '○$') { $allOk = $false } }
$title = $(if ($allOk) { '😺 平気だにゃ' } else { '🙀 なんか変だにゃ、見て' })
```

| 見張り四つ | 題 |
|---|---|
| 生存・見張り・片付け・受信箱が**全部 ○** | **`😺 平気だにゃ`** |
| **一つでも ○ でない** | **`🙀 なんか変だにゃ、見て`** |

**`🕘 定時の報せ` は使わなくなった。** 本文（`$body`）は一字も触っていない——
状態・台帳・見張り・使用量の四行はそのまま。

＊題の元になる `$alive` は、既にあった **L78-96** がそのまま組む。数え方は変えていない。

### 「？」（数えられなかった）は 🙀 の側

判定は「**○ で終わるか**」で見ている。`daily-notice.ps1` の印は四種——
`○`（生きている）／`×止`・`×無`・`×2` などの `×〜`（落ちている）／
**`？`（プロセスを数えられなかった。L94 の `catch` と L96 の `$n -lt 0`）**。

**`？` は `×` ではないが、`○` でもない。** ここは **🙀 の側**へ入れた。
**読めないことを「平気」と言わない**ため。

＊🙀 の字は `watch-notify.ps1` の `$PUSH_TITLE_OVER`（通知の題-1）と**同じ字**にしてある。
　見る側が「🙀 は見に行く合図」の一つだけを覚えれば済む。

## 2. 出る字の写し

**○のときは、台本を実際に回して確かめた**（`daily-notice.ps1 -DryRun`。本物の値で回る）。

```
😺 平気だにゃ
状態: 手待ち / 四枠まとめ（指示を受けた刻-1／連携の穴-1／欠陥調べ-1／通知の題…
台帳: 残り 0件
見張り: 生存○ 見張り○ 片付け○ 受信箱○
使用量: セッション 2% / 週全体 78% / 週Fable 55%
```

**×のときは、台本と同じ式へ印を与えて組んだ**（実際には止めていない）。

| 場合 | 本文の見張りの行 | 題 |
|---|---|---|
| **四つとも○**（いまの実状態） | `見張り: 生存○ 見張り○ 片付け○ 受信箱○` | **`😺 平気だにゃ`** |
| 見張りが落ちた | `見張り: 生存○ 見張り×2 片付け○ 受信箱○` | **`🙀 なんか変だにゃ、見て`** |
| 受信箱が落ちた | `見張り: 生存○ 見張り○ 片付け○ 受信箱×落` | **`🙀 なんか変だにゃ、見て`** |
| 数えられなかった | `見張り: 生存○ 見張り○ 片付け○ 受信箱？` | **`🙀 なんか変だにゃ、見て`** |
