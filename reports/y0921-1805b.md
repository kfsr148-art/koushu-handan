## 3. 使用量の鈴 — `resets_at` を**分の桁へ丸めた**

### 何が起きていたか

控え `usage-over.txt` の鍵は `種類|敷居 = resets_at` で、その値が**秒の下まで**入っていた。

```
週全体|80=2026-09-21T10:59:59.935482+00:00
```

**取るたびに小数の下が僅かに違うことがある。** すると**同じ窓なのに別の窓と見え、二度鳴る**。

### 直し

`watch-notify.ps1` に **`Win-Key`** を足し、控えへ置く鍵を **UTC の分の桁**へ丸めた。

```
2026-09-21T10:59:59.935482+00:00  →  2026-09-21T10:59Z
2026-09-21T10:59:59.111111+00:00  →  2026-09-21T10:59Z   ← 同じ字になる
2026-09-21T11:59:59.000000+00:00  →  2026-09-21T11:59Z   ← 窓が替われば変わる
よめない字                          →  よめない字            ← 丸められない物は捨てない
```

＊**札に出す字は丸める前の物**（`winRaw`）。読む人には秒まで見せる。
＊**いまの控えも一度だけ丸めておいた**（写しは `usage-over.txt.bak-20260921`）。
　丸め方が変わった初回に、無駄にもう一度鳴らさないため。

```
控えを丸めた : 週全体|80 … 2026-09-21T10:59:59.935482+00:00 → 2026-09-21T10:59Z
```

### 作り値

| 場合 | 鳴ったか | 控え |
|---|---|---|
| **甲 85%・窓 10:59:59.935482（はじめて）** | **鳴った** | `週全体|80=2026-09-21T10:59Z` |
| **乙 85%・窓 10:59:59.111111（同じ窓・小数だけ違う）** | **鳴らない** | 変わらず |
| **丙 85%・窓 11:59:59.000000（窓が替わった）** | **鳴った** | `週全体|80=2026-09-21T11:59Z` |

**本物の ntfy は一度も鳴らしていない・本物の控えにも触れていない**（写しに切り出して差し替えた）。

行数 **3552 → 3564**・構文の誤り0。写しは `watch-notify.ps1.bak-20260921`。
