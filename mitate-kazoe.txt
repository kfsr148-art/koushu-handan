【三】blockProfile の三つ（枠の埋まり方）  定義 L2765-2814、値は L2816-2818
---------------------------------------------------------------------------
  blockProfile は**雀頭の取り方を総当たり**して、最良の一つ（melds／good／weak）を選ぶ。
      fillRemain … max(0, 4 − melds)          … **面子4枠のうち、まだ埋まっていない数**（L2816）
      fillGood   … min(good, fillRemain)      … **そのうち好形で埋まる見込みの数**（L2817）
      fillWeak   … min(weak, fillRemain − fillGood) … **愚形どまりで埋まる見込みの数**（L2818）
    ＊三つとも「いま何本あるか」ではなく、**残り枠をどう埋めるかの見込み**の数。

  実例 … 3455m2367p1189s7z  → fillRemain=**3**／fillGood=**2**／fillWeak=**1**
  実例 … 19m19p19s1234567z  → fillRemain=**4**／fillGood=**0**／fillWeak=**0**（面子が一つも無い）
  実例 … 1345m1345p1345s1z  → fillRemain=**2**／fillGood=**0**／fillWeak=**1**
  実例 … 1112345678999m     → fillRemain=**1**／fillGood=**1**／fillWeak=**0**


【四】usagiLean の goodShapes  定義 L2670（宣言）／使う所 L4161
---------------------------------------------------------------------------
  何を数えるか … **良形の数**＝順子・暗刻・対子・両面。一色ずつ全分解し、
    良形最大→面子最大→弱形最大の順で選んだ分解のときの数（面子も良形に含める。L2670-2676）。
    ※七対子の形では「揃った対子の数」に置き換える（L3148）。
  usagiLean での使われ方（L4156-4163）… 上から順に、
      ①fillWeak === 0            → 攻め
      ②fillWeak >= 2             → 守り
      ③fillGood >= 3 かつ **goodShapes <= 3** → 守り
      ④それ以外                  → 黙る
  実例 … 3455m2367p1189s7z → goodShapes=**5**（fillWeak=1 なので①②に当たらず、
        fillGood=2 で③にも当たらない＝**黙る**）
  実例 … 1345m1345p1345s1z → goodShapes=**3**（fillWeak=1・fillGood=0 なので③にも当たらず黙る）
  実例 … 19m19p19s1234567z → goodShapes=**0**（fillWeak=0 なので①で**攻め**）
